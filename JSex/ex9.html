예제 9-9: JavaScript Math 객체 속성 분석 보고서

본 문서는 JavaScript 수학 내장 객체(Math)가 제공하는 주요 상수 속성(E, LN2, LN10, LOG2E, LOG10E, PI, SQRT1_2, SQRT2)과 다양한 수학적 연산 메서드들의 개념 및 활용법을 분석한 내용입니다.

학습 목표: 자바스크립트 내장 Math 객체의 수학 상수 속성을 이해하고, 삼각함수, 지수·로그, 반올림 및 최댓값/최솟값 연산 메서드들의 동작 원리를 익힙니다.

1. HTML 전체 소스코드

실습에 사용된 원본 HTML 및 JavaScript 코드입니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>예제 9-9 Math 속성</title>
</head>
<body>
    <h3>Math 객체 속성</h3>
    <p>Euler's 상수(E) : <b id="ca"></b></p>
    <p>자연로그2 LN2 : <b id="cca"></b></p>
    <p>자연로그10 LN10 : <b id="cnct"></b></p>
    <p>2진로그E(LOG2E) : <b id="ido"></b></p>
    <p>10진로그E(LOG10E): <b id="fxd"></b></p>
    <p>PI : <b id="prc"></b></p>
    <p>SQRT1_2 : <b id="str"></b></p>
    <p>SQRT2 : <b id="vlf"></b></p>
    <script>
        document.getElementById("ca").innerHTML = Math.E; 
        document.getElementById("cca").innerHTML = Math.LN2; 
        document.getElementById("cnct").innerHTML = Math.LN10; 
        document.getElementById("ido").innerHTML = Math.LOG2E; 
        document.getElementById("fxd").innerHTML = Math.LOG10E; 
        document.getElementById("prc").innerHTML = Math.PI; 
        document.getElementById("str").innerHTML = Math.SQRT1_2; 
        document.getElementById("vlf").innerHTML = Math.SQRT2; 
    </script>
</body>
</html>

2. JavaScript Math 주요 속성 상세 분석

속성명 사용 표현 동작 설명 및 의미
오일러 상수 Math.E 자연로그의 밑(Euler's constant)인 약 2.718 값을 반환합니다.
자연로그 2 Math.LN2 2의 자연로그 값(약 0.693)을 반환합니다.
자연로그 10 Math.LN10 10의 자연로그 값(약 2.302)을 반환합니다.
2진 로그 E Math.LOG2E 밑이 2인 오일러 상수의 로그 값(약 1.442)을 반환합니다.
10진 로그 E Math.LOG10E 밑이 10인 오일러 상수의 로그 값(약 0.434)을 반환합니다.
원주율 (PI) Math.PI 원주율 파이 값인 약 3.14159...를 반환합니다.
1/2의 제곱근 Math.SQRT1_2 1/2의 제곱근(또는 1을 2의 제곱근으로 나눈 값, 약 0.707)을 반환합니다.
2의 제곱근 Math.SQRT2 2의 제곱근 값(약 1.414)을 반환합니다.

3. JavaScript Math 주요 메서드 상세 분석

파트 1 (기준 변수: x = 1, y = 3)

메서드명 사용 예시 동작 설명 및 의미
Math.abs() Math.abs(1) 숫자의 절대값을 반환합니다. ➔ 1
Math.acos() Math.acos(1) 아크코사인(역코사인) 값을 라디안 단위로 반환합니다. ($\arccos(1) = 0$) ➔ 0
Math.acosh() Math.acosh(1) 역쌍곡코사인 값을 반환합니다. ($\operatorname{arcosh}(1) = 0$) ➔ 0
Math.asin() Math.asin(1) 아크사인(역사인) 값을 반환합니다. ($\arcsin(1) = \pi/2$) ➔ 1.57079...
Math.asinh() Math.asinh(1) 역쌍곡사인 값을 반환합니다. ➔ 0.88137...
Math.atan() Math.atan(1) 아크탄젠트 값을 반환합니다. ($\arctan(1) = \pi/4$) ➔ 0.78539...
Math.atan2() Math.atan2(1, 3) 주어진 인수(y, x)의 아크탄젠트 값을 반환합니다. ➔ 0.32175...
Math.cbrt() Math.cbrt(1) 숫자의 세제곱근(cube root)을 반환합니다. ($\sqrt[3]{1} = 1$) ➔ 1
Math.ceil() Math.ceil(1) 소수점이 있는 경우 크거나 같은 정수 중 가장 작은 수를 반환(올림)합니다. ➔ 1

파트 2 (기준 변수: x = 1.00, y = 3 등)

메서드명 사용 예시 동작 설명 및 의미
Math.cos() Math.cos(1) 주어진 각도(라디안)의 코사인 값을 반환합니다. ➔ 0.54030...
Math.cosh() Math.cosh(1) 쌍곡코사인 값을 반환합니다. ➔ 1.54308...
Math.exp() Math.exp(1) 오일러 상수 $e$의 거듭제곱($e^1$) 값을 반환합니다. ➔ 2.71828...
Math.floor() Math.floor(1) 인수로 전달된 숫자와 같거나 작은 정수 중 가장 큰 수(내림)를 반환합니다. ➔ 1
Math.log() Math.log(1) 자연로그 값($\ln(1)$)을 반환합니다. ➔ 0
Math.max() Math.max(1, 3, 0.3, 12) 전달된 인수들 중 가장 큰 값을 반환합니다. ➔ 12
Math.min() Math.min(1, 3, 0.3, 12) 전달된 인수들 중 가장 작은 값을 반환합니다. ➔ 0.3
Math.pow() Math.pow(1, 3) 베이스 숫자의 지정된 거듭제곱 값($1^3$)을 반환합니다. ➔ 1
Math.random() Math.random() 0 이상 1 미만의 무작위 난수(Pseudo-random number)를 반환합니다. ➔ (실행 시마다 랜덤 소수)

파트 3 (기준 변수: x = 1.234)

메서드명 사용 예시 동작 설명 및 의미
Math.round() Math.round(1.234) 소수점 이하 첫째 자리에서 반올림하여 가장 가까운 정수를 반환합니다. ➔ 1
Math.sin() Math.sin(1.234) 주어진 각도(라디안)의 사인 값을 반환합니다. ➔ 0.94248...
Math.sinh() Math.sinh(1.234) 쌍곡사인(Hyperbolic Sine) 값을 반환합니다. ➔ 1.56543...
Math.sqrt() Math.sqrt(1.234) 숫자의 양의 제곱근(Square Root)을 반환합니다. ($\sqrt{1.234}$) ➔ 1.11085...
Math.tan() Math.tan(1.234) 주어진 각도(라디안)의 탄젠트 값을 반환합니다. ➔ 2.91501...
Math.tanh() Math.tanh(1.234) 쌍곡탄젠트 값을 반환합니다. ➔ 0.84339...
Math.trunc() Math.trunc(1.234) 숫자의 소수점 이하를 버리고 정수 부분만 반환합니다. ➔ 1

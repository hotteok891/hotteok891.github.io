예제 9-3: 객체와 프로토타입 (Prototype)

본 페이지는 생성자 함수와 프로토타입 기반 메서드 공유 구조를 분석하여, 메모리 효율성과 this 바인딩의 원리를 다루는 학습 대시보드입니다.

1. 소스 코드 목록

분석 대상이 된 예제 9-3 원본 HTML 코드입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-3프로토타입</title>
</head>
<body>
    <h3>프로토타입</h3>
    <script>
        function Human(name, age, sex, speed) {
            this.name = name;                       
            this.age = age;
            this.sex = sex;
            this.speed = speed;
        }

        Human.prototype.walk = function() { this.speed = 5; }
        Human.prototype.run = function() { this.speed += 3; }

        var cmHuman = new Human("Park", 12, "male", 20);
        var cfHuman = new Human("Kim", 12, "female", 15);

        do {
            document.write("Name:" + cmHuman.name + " run:" + cmHuman.speed + "<br />");
            cmHuman.run();
            document.write("Name:" + cfHuman.name + " run:" + cfHuman.speed + "<br />");
            cfHuman.run();
        } while (cmHuman.speed < 35);

        cmHuman.walk();
        cfHuman.walk();

        document.write("Name:" + cmHuman.name + " walk:" + cmHuman.speed + "<br />");
        document.write("Name:" + cfHuman.name + " walk:" + cfHuman.speed + "<br />");
    </script>
</body>
</html>

2. JavaScript 객체 및 프로토타입 개념 분석

1) 생성자 함수 (Constructor Function)

function Human(...)은 새로운 인스턴스를 생성하는 생성자 함수입니다. new 키워드와 함께 호출되면 새로운 빈 객체가 생성되고, this가 해당 객체를 가리키며 속성들이 초기화됩니다.

2) 프로토타입 (Prototype) 및 메모리 효율성

JavaScript의 모든 함수는 prototype 속성을 가집니다. 메서드를 프로토타입 객체에 등록하면 메모리를 대폭 절약할 수 있습니다.

구분 인스턴스 속성 (Instance Properties) 프로토타입 메서드 (Prototype Methods)
예시 this.name, this.speed Human.prototype.walk, Human.prototype.run
할당 방식 각 인스턴스마다 독자적인 메모리 공간에 개별 저장 프로토타입 메모리에 1개만 생성되어 모든 인스턴스가 공유
장점 객체별로 고유한 데이터 유지 가능 동일한 기능을 중복 생성하지 않아 메모리 낭비 방지

3) this 바인딩의 의미: 메서드 내부의 this는 호출 시점에 해당 메서드를 실행한 객체 인스턴스를 동적으로 참조합니다. (예: cmHuman.run() 호출 시 this는 cmHuman을 가리킴)

3. 실행 과정 분석 (do...while 반복문)

조건식 cmHuman.speed < 35에 따라 Park의 속도만을 기준으로 반복이 제어됩니다.

  1. 1차 루프: Park(20) 출력 ➔ Park 속도 23 | Kim(15) 출력 ➔ Kim 속도 18 (조건: 23 < 35 참)
  2. 2차 루프: Park(23) 출력 ➔ Park 속도 26 | Kim(18) 출력 ➔ Kim 속도 21 (조건: 26 < 35 참)
  3. 3차 루프: Park(26) 출력 ➔ Park 속도 29 | Kim(21) 출력 ➔ Kim 속도 24 (조건: 29 < 35 참)
  4. 4차 루프: Park(29) 출력 ➔ Park 속도 32 | Kim(24) 출력 ➔ Kim 속도 27 (조건: 32 < 35 참)
  5. 5차 루프: Park(32) 출력 ➔ Park 속도 35 | Kim(27) 출력 ➔ Kim 속도 30 (조건: 35 < 35 거짓 ➔ 반복 종료)

4. 핵심 JavaScript 메서드 요약

메서드 / 속성 역할 및 설명
trim() 문자열 앞뒤의 불필요한 공백을 제거합니다.
toLowerCase() 영문 대문자를 모두 소문자로 변환하여 비교 오류를 방지합니다.
length 문자열의 글자 수 또는 배열의 항목 개수를 반환합니다.
indexOf() 특정 문자열이 처음 나타나는 인덱스를 반환하며, 없으면 -1을 반환합니다.
includes() 특정 문자열이 포함되어 있는지 여부를 true 또는 false로 반환합니다.
replaceAll() 문자열 내에서 일치하는 모든 부분을 다른 문자열로 교체합니다.
split() 특정 구분자(,, \n, 공백 등)를 기준으로 문자열을 나누어 배열로 반환합니다.

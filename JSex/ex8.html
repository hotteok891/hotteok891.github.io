예제 9-8: JavaScript Number 객체 메서드 분석 보고서

본 문서는 JavaScript 숫자(Number) 객체가 제공하는 다양한 정적 메서드 및 인스턴스 메서드(isFinite, isInteger, isNaN, toExponential, toFixed, toPrecision, toString, valueOf)의 동작 원리와 활용법을 분석한 내용입니다.

학습 목표: 숫자 데이터의 유효성 검증 방법과 문자열 포맷팅 및 변환 메서드들의 활용법을 익힙니다.

1. HTML 전체 소스코드

실습에 사용된 원본 HTML 및 JavaScript 코드입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-8Number 메소드</title>
</head>
<body>
    <h3>Number 메소드</h3>
    <p>isFinite : <b id="ca"></b></p>
    <p>isInteger : <b id="cca"></b></p>
    <p>isNaN : <b id="cnct"></b></p>
    <p>toExponential : <b id="ido"></b></p>
    <p>toFixed : <b id="fxd"></b></p>
    <p>toPrecision : <b id="prc"></b></p>
    <p>toString : <b id="str"></b></p>
    <p>valueOf : <b id="vlf"></b></p>
    <script>
        var num = 1234.567;
        document.getElementById("ca").innerHTML = Number.isFinite(num);
        document.getElementById("cca").innerHTML = Number.isInteger(num);
        document.getElementById("cnct").innerHTML = Number.isNaN(num);
        document.getElementById("ido").innerHTML = num.toExponential(num);
        document.getElementById("fxd").innerHTML = num.toFixed(1);
        document.getElementById("prc").innerHTML = num.toPrecision(4);
        document.getElementById("str").innerHTML = num.toString(num);
        document.getElementById("vlf").innerHTML = num.valueOf(num);
    </script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Number 메소드)을 정의합니다.
  • <p> 및 <b id="..."> 태그: 각 Number 메서드의 연산 결과를 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, fxd, prc 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Number 주요 메서드 상세 분석

메서드명 사용 예시 동작 설명 및 결과 (기준 값: 1234.567)
Number.isFinite() Number.isFinite(num) 값이 유한수인지 검사합니다. ➔ true
Number.isInteger() Number.isInteger(num) 값이 정수인지 검사합니다. (소수점이 있으므로 거짓) ➔ false
Number.isNaN() Number.isNaN(num) 값이 NaN(Not-a-Number)인지 검사합니다. ➔ false
num.toExponential() num.toExponential() 숫자를 지수 표기법으로 변환합니다. ➔ 1.234567e+3
num.toFixed(digits) num.toFixed(1) 소수점 이하 자릿수를 지정하여 반올림된 문자열로 반환합니다. ➔ 1234.6
num.toPrecision(digits) num.toPrecision(4) 전체 유효숫자 개수를 지정하여 반환합니다. ➔ 1235
num.toString() num.toString() 숫자를 문자열로 변환합니다. ➔ 1234.567
num.valueOf() num.valueOf() Number 객체의 원시 숫자 값을 반환합니다. ➔ 1234.567

4. 실행 과정 및 브라우저 최종 출력 결과

Number 메소드 isFinite : true isInteger : false isNaN : false toExponential : 1.234567e+3 toFixed : 1234.6 toPrecision : 1235 toString : 1234.567 valueOf : 1234.567

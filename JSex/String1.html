예제 9-4, 9-5, 9-6 분석 문서

HTML 문서 구조와 DOM 요소 제어 방식, 생성자 함수, 프로토타입(Prototype) 확장, 그리고 JavaScript String 객체의 다양한 속성과 메서드 활용법을 분석한 학습용 대시보드입니다.

String 메서드의 목적: 문자열 데이터를 직접 수정하지 않고, JavaScript가 제공하는 내장 기능을 통해 원하는 형태로 검색·추출·변경·변환하여 편리하게 다루기 위함입니다.

1. 분석 대상 원본 소스코드

예제 9-4(Prototype & String 속성), 예제 9-5(String 메서드 1), 예제 9-6(String 메서드 2)의 실습 코드입니다.

<!-- 예제 9-4: String 속성 및 프로토타입 -->
<script>
    function Human(name, job, birth) {
        this.name = name; 
        this.job = job; 
        this.birth = birth; 
    }
    Human.prototype.age = 23; 
    var kim = new Human("Kim", "student", 2003); 
    document.getElementById("proto").innerHTML = kim.age; 
    document.getElementById("cnst").innerHTML = kim.constructor; 
    document.getElementById("Lth").innerHTML = kim.name.length; 
</script>

2. JavaScript 객체 및 프로토타입 개념 분석

개념 요소 코드 표현 핵심 역할 및 동작 원리
생성자 함수 function Human(...) 유사한 구조의 객체를 생성하기 위한 설계도(템플릿) 역할
프로토타입 확장 Human.prototype.age = 23; 프로토타입 체인을 통해 모든 인스턴스가 공유하는 공통 속성 정의
생성자 참조 kim.constructor 인스턴스를 생성한 원본 생성자 함수(Human) 참조 반환
String 속성 kim.name.length 문자열 원시 값이 래퍼 객체로 변환되어 길이를 반환

3. String 메서드 상세 분석

파트 1 (예제 9-5 관련)

메서드명 사용 예시 동작 설명 및 결과
charAt(index) str.charAt(0) 특정 인덱스(0번째)에 위치한 문자 추출 ➔ h
charCodeAt(index) str.charCodeAt(0) 특정 인덱스 문자의 유니코드 값 반환 ➔ 104
concat(string) str.concat(str2) 문자열을 서로 결합 ➔ hello, welcome to AI Software!!???
indexOf(substring) str.indexOf("AI") 지정한 문자열이 처음 등장하는 위치(인덱스) 검색 ➔ 17
lastIndexOf(substring) str.lastIndexOf("to") 지정한 문자열이 마지막으로 등장하는 위치 검색 ➔ 14
replace(target, replacement) str.replace("hello", "Good Bye") 특정 문자열을 찾아 다른 문자열로 치환 ➔ Good Bye, welcome to AI Software!!

파트 2 (예제 9-6 관련)

메서드명 사용 예시 동작 설명 및 결과
match(pattern) str.match("AI") 일치하는 항목을 검색하여 배열/결과 반환 ➔ AI
search(pattern) str.search("Software") 문자열이 처음 시작되는 인덱스 위치 반환 ➔ 20
slice(start, end) str.slice(7, 12) 인덱스 7부터 11까지의 부분 문자열 추출 ➔ welco
split(separator) str.split(" ") 구분자(공백)를 기준으로 문자열 분할 ➔ 배열 생성
toUpperCase() str.toUpperCase() 모든 영문 소문자를 대문자로 변환 ➔ HELLO, WELCOME, AI, SOFTWARE
toString() str2.toString() 숫자 데이터를 문자열 형태로 변환 ➔ "5678"

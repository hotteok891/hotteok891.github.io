예제 9-2: this와 객체 생성자

이 예제는 생성자 함수를 통해 사람 객체 두 개를 생성하고, 독립적인 속성 값들을 메서드를 통해 제어하는 프로그램의 동작 원리를 설명합니다.

핵심 포인트: new Human(...)을 두 번 실행하여 생성된 cmHuman과 cfHuman은 서로 독립적인 메모리 공간을 가지며, 각자의 이름과 속도 값을 개별적으로 관리합니다.

1. HTML 원본 코드

분석 대상이 된 원본 프로그램 코드입니다. 로직은 변경하지 않고 그대로 반영했습니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-2this객체생성자</title>
</head>
<body>
<h3>객체생성</h3>    
    <script>
        function Human(name, age, sex, speed) {
            this.name = name;
            this.age = age;
            this.sex = sex;
            this.speed = speed;
            this.walk = function () { this.speed = 10; }
            this.run = function () { this.speed += 4; }
        }
        
        var cmHuman = new Human("Park", 12, "male", 20);
        var cfHuman = new Human("Kim", 12, "female", 15);
        
        do {
            document.write("Name:" + cmHuman.name + " run:" + cmHuman.speed + "<br />");
            cmHuman.run();
            document.write("Name:" + cfHuman.name + " run:" + cfHuman.speed + "<br />");
            cfHuman.run();
        } while (cmHuman.speed < 35);
        
        cmHuman.walk();
        cfHuman.walk();
        
        document.write("Name:" + cmHuman.name + " walk:" + cmHuman.speed + "<br />");
        document.write("Name:" + cfHuman.name + " walk:" + cmHuman.speed + "<br />");
    </script>
</body>
</html>

2. JavaScript 객체와 생성자 함수

3-1. 생성자 함수와 this

Human은 사람 객체를 찍어내는 설계도 역할을 하는 생성자 함수입니다. new 키워드와 함께 호출될 때 this는 새로 만들어지는 객체 자신을 가리킵니다.

cmHuman 객체 인스턴스

name: "Park"
age: 12
sex: "male"
speed: 20

cfHuman 객체 인스턴스

name: "Kim"
age: 12
sex: "female"
speed: 15

3. 반복문 및 실행 과정 분석

반복 조건은 Park의 속도(cmHuman.speed)만을 기준으로 검사하며, 총 4회 반복 후 종료됩니다.

반복 횟수 Park 출력 속도 Park run() 후 Kim 출력 속도 Kim run() 후 조건 검사 (cmHuman.speed < 35)
1회차 20 24 15 19 24 < 35 (참)
2회차 24 28 19 23 28 < 35 (참)
3회차 28 32 23 27 32 < 35 (참)
4회차 32 36 27 31 36 < 35 (거짓, 종료)

4. 프로그램 최종 출력 결과

반복문 종료 후 두 객체의 walk() 메서드가 실행되어 속도가 모두 10으로 재설정됩니다.

Name:Park run:20 Name:Kim run:15 Name:Park run:24 Name:Kim run:19 Name:Park run:28 Name:Kim run:23 Name:Park run:32 Name:Kim run:27 Name:Park walk:10 Name:Kim walk:10
  1. Park(20)과 Kim(15)의 초기 상태를 순서대로 출력합니다.
  2. 각각의 run() 메서드를 호출하여 속도를 4씩 증가시킵니다.
  3. Park의 속도가 35 미만일 동안 위 과정을 반복합니다.
  4. Park 속도가 36이 되는 순간 조건문이 거짓이 되어 반복을 종료합니다.
  5. walk()를 호출해 두 사람의 속도를 각각 10으로 설정한 뒤 최종 출력합니다.

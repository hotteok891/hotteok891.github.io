객체 리터럴과 반복문 분석

본 페이지는 입력된 JavaScript 예제 프로그램을 완벽하게 분석하여 객체(Object), 속성, 메서드, this, 그리고 do...while 반복문의 동작 원리를 이해하기 쉽게 정리한 학습 가이드입니다.

학습 참고 포인트: 이 예제는 제목에 ‘객체 생성자’로 언급되어 있으나, 실제로는 new 키워드를 사용하는 생성자 함수가 아닌 객체 리터럴 방식으로 객체를 생성하고 활용합니다.

1. 제공된 HTML 원본 코드

원본 프로그램의 로직과 구조를 변경하지 않고 그대로 수록한 코드입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-1객체 생성자</title>
</head>
<body>
<h3>객체생성</h3>    
    <script>
       var human = { 
            name: "Park", 
            age: 40, 
            sex: "female", 
            speed: 20,    // 속성
            walk : function(){ this.speed = 5; },      // 걷기 메서드
            run : function(){ this.speed += 3; },     // 달리기 메서드
        };
        
        do {
            document.write("이름:" + human.name + " 달리기:" + human.speed + "<br />");
            human.run();
        } while( human.speed < 35 )

        human.walk();
        document.write("이름:" + human.name + " 걷기:" + human.speed + "<br />");
    </script>
</body>
</html>

2. 객체(Object), 속성, 메서드 및 this 이해하기

객체(Object)는 관련된 데이터와 기능을 하나로 묶어 관리하는 단위입니다. human 객체는 사람의 신상 정보와 행동(메서드)을 동시에 담고 있습니다.

구분 코드 표현 설명
속성 (Property) name: "Park", age: 40 등 객체가 가지는 고유의 데이터 값
메서드 (Method) walk(), run() 객체가 수행할 수 있는 동작(함수)
this 키워드 this.speed += 3 현재 메서드를 호출한 객체(human) 자신을 가리킴

3. do...while 반복문 실행 흐름 분석

do...while 문은 조건 검사 전에 블록 내부의 코드를 무조건 먼저 한 번 실행한 후 조건을 평가합니다.

반복 횟수 출력되는 speed run() 실행 후 speed 변화 반복 조건 검사 (speed < 35)
1회차 20 20 + 3 = 23 23 < 35 (참) → 계속 반복
2회차 23 23 + 3 = 26 26 < 35 (참) → 계속 반복
3회차 26 26 + 3 = 29 29 < 35 (참) → 계속 반복
4회차 29 29 + 3 = 32 32 < 35 (참) → 계속 반복
5회차 32 32 + 3 = 35 35 < 35 (거짓) → 반복 종료
속도 35는 5회차 run() 실행으로 만들어지지만, 조건 검사 시점에서 거짓이 되므로 다음 반복은 실행되지 않습니다.

4. 프로그램 최종 출력 및 실행 흐름

반복문이 종료된 후 human.walk()가 실행되어 속도가 5로 재설정됩니다.

이름:Park 달리기:20 이름:Park 달리기:23 이름:Park 달리기:26 이름:Park 달리기:29 이름:Park 달리기:32 이름:Park 걷기:5

핵심 실행 순서:

  • 1. human 객체 생성 및 초기 속도 20 설정
  • 2. do...while 루프 진입: 출력(20) → run() 실행(23)
  • 3. 속도가 35 미만일 동안 23, 26, 29, 32 출력 및 속도 증가 반복
  • 4. 속도가 35가 되는 순간 반복문 탈출
  • 5. human.walk() 호출로 속도를 5로 변경
  • 6. 마지막 걷기 속도 결과 출력 (이름:Park 걷기:5)

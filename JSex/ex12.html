예제 9-12: JavaScript Math 객체 메서드3 분석 보고서

본 문서는 JavaScript 수학 내장 객체(Math)가 제공하는 반올림, 삼각함수, 제곱근, 정수 추출 등 주요 메서드(round, sin, sinh, sqrt, tan, tanh, trunc)의 동작 원리와 활용법을 분석한 내용입니다.

학습 목표: 기준 변수 x = 1.234를 적용했을 때 각 수학 메서드의 반환 값을 이해하고, DOM 요소를 통한 바인딩 출력 방식을 학습합니다.

1. HTML 전체 소스코드

실습에 사용된 원본 HTML 및 JavaScript 코드입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-12Math 메소드3</title>
</head>
<body>
    <h3>Math 객체 메소드3 var x =1.234</h3>
    <p>Math.round(x) : <b id="ca"></b></p>
    <p>Math.sin(x) : <b id="cca"></b></p>
    <p>Math.sinh(x) : <b id="cnct"></b></p>
    <p>Math.sqrt(x)) : <b id="ido"></b></p>
    <p>Math.tan(x): <b id="vlf"></b></p>
    <p>Math.tanh(x): <b id="fxd"></b></p>
    <p>Math.trunc(x) : <b id="prc"></b></p>
    <script>
        var x = 1.234;
        document.getElementById("ca").innerHTML = Math.round(x);
        document.getElementById("cca").innerHTML = Math.sin(x);
        document.getElementById("cnct").innerHTML = Math.sinh(x);
        document.getElementById("ido").innerHTML = Math.sqrt(x); 
        document.getElementById("vlf").innerHTML = Math.tan(x);
        document.getElementById("fxd").innerHTML = Math.tanh(x);
        document.getElementById("prc").innerHTML = Math.trunc(x);
    </script>
</body>
</html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목과 기준 변수 값(var x = 1.234)을 함께 표시합니다.
  • <p> 및 <b id="..."> 태그: 각 Math 메서드의 연산 결과를 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, ido 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Math 주요 메서드 상세 분석 (기준 변수: x = 1.234)

메서드명 사용 예시 동작 설명 및 의미
Math.round() Math.round(1.234) 소수점 이하 첫째 자리에서 반올림하여 가장 가까운 정수를 반환합니다. ➔ 1
Math.sin() Math.sin(1.234) 주어진 각도(라디안)의 사인 값을 반환합니다. ➔ 0.942488801931616
Math.sinh() Math.sinh(1.234) 쌍곡사인(Hyperbolic Sine) 값을 반환합니다. ➔ 1.5654395346894052
Math.sqrt() Math.sqrt(1.234) 숫자의 양의 제곱근(Square Root)을 반환합니다. ($\sqrt{1.234}$) ➔ 1.1108555263624835
Math.tan() Math.tan(1.234) 주어진 각도(라디안)의 탄젠트 값을 반환합니다. ➔ 2.915011707577517
Math.tanh() Math.tanh(1.234) 쌍곡탄젠트 값을 반환합니다. ➔ 0.8433983693437295
Math.trunc() Math.trunc(1.234) 숫자의 소수점 이하를 버리고 정수 부분만 반환합니다. ➔ 1

예제 9-7 & 9-8: Number 객체 속성 및 메서드 분석

본 문서는 JavaScript 숫자(Number) 객체가 제공하는 주요 정적 속성(MAX_VALUE, MIN_VALUE, POSITIVE_INFINITY, NEGATIVE_INFINITY)과 유틸리티 메서드들의 개념 및 표현 범위를 분석한 내용입니다.

학습 목표: JavaScript에서 숫자가 다루어지는 방식과 표현 한계, 그리고 숫자 검증 및 포맷팅 메서드의 활용법을 익힙니다.

1. HTML 전체 소스코드 (예제 9-7 및 9-8)

실습에 사용된 원본 HTML 및 JavaScript 코드입니다.

<!DOCTYPE html><html><head><title>예제9-7Number 속성</title></head><body>
<h3>Number 속성</h3>
<p>MAX_VALUE : <b id="ca"></b></p>
<p>MIN_VALUE : <b id="cca"></b></p>
<p>POSITIVE_INFINITY : <b id="cnct"></b></p>
<p>NEGATIVE_INFINITY : <b id="ido"></b></p>
<script>
    document.getElementById("ca").innerHTML = Number.MAX_VALUE; 
    document.getElementById("cca").innerHTML = Number.MIN_VALUE; 
    document.getElementById("cnct").innerHTML = Number.POSITIVE_INFINITY; 
    document.getElementById("ido").innerHTML = Number.NEGATIVE_INFINITY; 
</script></body></html>

<!DOCTYPE html><html><head><title>예제9-8Number 메소드</title></head><body>
<h3>Number 메소드</h3>
<p>isFinite : <b id="ca"></b></p><p>isInteger : <b id="cca"></b></p><p>isNaN : <b id="cnct"></b></p><p>toExponential : <b id="ido"></b></p>
<p>toFixed : <b id="fxd"></b></p><p>toPrecision : <b id="prc"></b></p><p>toString : <b id="str"></b></p><p>valueOf : <b id="vlf"></b></p>
<script>
    var num = 1234.567; 
    document.getElementById("ca").innerHTML = Number.isFinite(num); 
    document.getElementById("cca").innerHTML = Number.isInteger(num); 
    document.getElementById("cnct").innerHTML = Number.isNaN(num); 
    document.getElementById("ido").innerHTML = num.toExponential(); 
    document.getElementById("fxd").innerHTML = num.toFixed(1); 
    document.getElementById("prc").innerHTML = num.toPrecision(4); 
    document.getElementById("str").innerHTML = num.toString(); 
    document.getElementById("vlf").innerHTML = num.valueOf(); 
</script></body></html>

2. HTML 구조 및 DOM 요소 설명

  • <h3>: 화면 대표 제목(Number 속성 / 메서드)을 정의합니다.
  • <p> 및 <b id="..."> 태그: Number 객체의 속성 및 메서드 연산 결과를 동적으로 바인딩하여 출력하기 위한 DOM 구역입니다. ca, cca, cnct 등의 고유 ID가 부여되어 있습니다.

3. JavaScript Number 주요 속성 및 메서드 상세 분석

1) Number 주요 속성

속성명 사용 표현 동작 설명 및 의미
Number.MAX_VALUE Number.MAX_VALUE JavaScript에서 표현할 수 있는 가장 큰 양의 숫자를 나타냅니다. (약 1.79E+308) 초과 시 무한대(Infinity)로 처리됩니다.
Number.MIN_VALUE Number.MIN_VALUE JavaScript에서 표현할 수 있는 0에 가장 가까운 양의 숫자를 나타냅니다. (약 5E-324)
Number.POSITIVE_INFINITY Number.POSITIVE_INFINITY 양의 무한대(Infinity)를 나타내는 특수한 상숫값입니다.
Number.NEGATIVE_INFINITY Number.NEGATIVE_INFINITY 음의 무한대(-Infinity)를 나타내는 특수한 상숫값입니다.

2) Number 주요 메서드 (기준 값: 1234.567)

메서드명 사용 예시 동작 설명 및 결과
Number.isFinite() Number.isFinite(num) 값이 유한수인지 검사합니다. ➔ true
Number.isInteger() Number.isInteger(num) 값이 정수인지 검사합니다. (소수점이 있으므로 거짓) ➔ false
Number.isNaN() Number.isNaN(num) 값이 NaN(Not-a-Number)인지 검사합니다. ➔ false
num.toExponential() num.toExponential() 숫자를 지수 표기법으로 변환합니다. ➔ 1.234567e+3
num.toFixed(digits) num.toFixed(1) 소수점 이하 자릿수를 지정하여 반올림된 문자열로 반환합니다. ➔ 1234.6
num.toPrecision(digits) num.toPrecision(4) 전체 유효숫자 개수를 지정하여 반환합니다. ➔ 1235
num.toString() num.toString() 숫자를 문자열로 변환합니다. ➔ 1234.567
num.valueOf() num.valueOf() Number 객체의 원시 숫자 값을 반환합니다. ➔ 1234.567

4. 실행 과정 및 브라우저 최종 출력 결과

Number 속성 MAX_VALUE : 1.7976931348623157e+308 MIN_VALUE : 5e-324 POSITIVE_INFINITY : Infinity NEGATIVE_INFINITY : -Infinity

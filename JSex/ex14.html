JavaScript 내장 객체 분석

예제 9-17: JavaScript Date 객체 메서드 분석 보고서

본 문서는 JavaScript 내장 객체인 Date를 활용하여 현재 시스템의 연도, 월, 일, 요일, 시, 분, 초 및 타임스탬프 정보를 추출하고 화면에 출력하는 예제 코드를 분석한 내용입니다.

학습 목표: 시스템 날짜 및 시간 정보를 가져오는 다양한 Date 메서드의 반환 형식과 월/요일 처리 방식을 이해합니다.

1. HTML 전체 소스코드

실습에 사용된 원본 HTML 및 JavaScript 코드입니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제9-17Date 객체 메소드 예제</title>
    <meta charset="utf-8">
</head>
<body>
    <h3>Date 객체 메소드 활용</h3>
    <p><b>getDate()</b> : 오늘 날짜 (1~31) → <span id="ca"></span></p>
    <p><b>getDay()</b> : 요일 (0~6, 일=0) → <span id="cca"></span></p>
    <p><b>getFullYear()</b> : 연도 → <span id="cnct"></span></p>
    <p><b>getHours()</b> : 현재 시 (0~23) → <span id="ido"></span></p>
    <p><b>getMilliseconds()</b> : 밀리초 (0~999) → <span id="vlf"></span></p>
    <p><b>getMinutes()</b> : 분 (0~59) → <span id="fxd"></span></p>
    <p><b>getMonth()</b> : 월 (0~11, 0=1월) → <span id="prc"></span></p>
    <p><b>getSeconds()</b> : 초 (0~59) → <span id="exp"></span></p>
    <p><b>getTime()</b> : 1970년 1월 1일부터 현재까지의 밀리초 → <span id="str"></span></p>
    <script>
        var today = new Date();
        document.getElementById("ca").innerText = today.getDate();
        document.getElementById("cca").innerText = today.getDay();
        document.getElementById("cnct").innerText = today.getFullYear();
        document.getElementById("ido").innerText = today.getHours();
        document.getElementById("vlf").innerText = today.getMilliseconds();
        document.getElementById("fxd").innerText = today.getMinutes();
        document.getElementById("prc").innerText = today.getMonth();
        document.getElementById("exp").innerText = today.getSeconds();
        document.getElementById("str").innerText = today.getTime();
    </script>
</body>
</html>

📅 실시간 Date 메서드 실행 화면

getDate() : 오늘 날짜 (1~31) →

getDay() : 요일 (0~6, 일=0) →

getFullYear() : 연도 →

getHours() : 현재 시 (0~23) →

getMilliseconds() : 밀리초 (0~999) →

getMinutes() : 분 (0~59) →

getMonth() : 월 (0~11, 0=1월) →

getSeconds() : 초 (0~59) →

getTime() : 타임스탬프 (밀리초) →

2. HTML 구조 및 DOM 요소 설명

  • <h3> 및 <p> 태그: 날짜 및 시간 정보를 항목별로 나누어 가독성 있게 표현합니다.
  • <span id="..."> 태그: JavaScript가 시스템에서 산출한 날짜/시간 데이터를 innerText로 동주입하는 대상 영역입니다.

3. JavaScript Date 객체 주요 메서드 상세 분석

메서드명 반환 범위 및 설명
getDate() 오늘 날짜(일)를 1부터 31 사이의 정수로 반환합니다.
getDay() 요일을 숫자로 반환합니다. (0: 일요일, 1: 월요일, ..., 6: 토요일)
getFullYear() 4자리 연도(예: 2026)를 반환합니다.
getHours() 현재 시간(시)을 0부터 23 사이의 정수로 반환합니다.
getMilliseconds() 현재 초 내의 밀리초를 0부터 999 사이의 정수로 반환합니다.
getMinutes() 현재 분을 0부터 59 사이의 정수로 반환합니다.
getMonth() 월을 반환합니다. 주의할 점은 0이 1월, 11이 12월을 의미하므로 실제 월을 구할 때는 1을 더해주어야 합니다.
getSeconds() 현재 초를 0부터 59 사이의 정수로 반환합니다.
getTime() 1970년 1월 1일 00:00:00 UTC 기준부터 현재까지 경과한 시간을 밀리초 단위(Timestamp)로 반환합니다.

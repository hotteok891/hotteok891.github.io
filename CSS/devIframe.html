div vs iframe

단순한 구조적 영역을 나누는 컨테이너와 독립된 또 하나의 웹페이지를 통째로 중첩하는 프레임의 이해

<div> CSS 레이아웃 박스

Division의 약자로, 아무런 의미를 가지지 않는 순수한 블록 레벨의 컨테이너입니다. 주로 CSS 스타일링을 적용하거나 자바스크립트로 특정 영역을 제어하기 위해 묶어주는 역할을 합니다.

  • 현재 문서의 일부로 작동 (스타일 시트 공유 가능)
  • 레이아웃 분할 및 컴포넌트 단위 그룹화에 필수
<div class="box">
    <p>현재 페이지의 콘텐츠</p>
</div>
<iframe> 인라인 프레임

Inline Frame의 약자로, 현재 웹페이지 안에 완전히 독립된 또 다른 HTML 문서(외부 페이지)를 중첩하여 액자처럼 삽입합니다. 독립된 창(Window) 인터페이스를 가집니다.

  • 부모 페이지와 완벽히 분리된 격리 공간 (스타일 독립)
  • 외부 지도(구글맵), 유튜브 영상 embedded 등에 활용
<iframe src="https://example.com" 
        width="100%"></iframe>

⚡ 비주얼 라이브 프리뷰 라이트

■ div 구현 (현재 문서 안의 요소)
<div class="custom-div">...</div>

여기는 div 내부 공간입니다.

현재 웹사이트의 CSS 디자인과 테마를 그대로 이어받아 동화됩니다.

■ iframe 구현 (독립된 또 다른 페이지 분리)
<iframe src="internal_sandboxed">

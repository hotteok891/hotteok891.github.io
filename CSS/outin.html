CSS 연결 방식 가이드

웹 페이지를 꾸미는 CSS 방식 중 대표적인 두 가지 방식인 **내부 스타일 시트**와 **외부 스타일 시트**의 개념과 사용법을 다룹니다.

METHOD 01

내부 스타일 시트

HTML 문서 내부 <head> 태그 안에 <style> 태그를 작성하여 스타일을 지정하는 방식입니다.

METHOD 02

외부 스타일 시트

별도의 .css 파일을 만들고, HTML 문서에서 <link> 태그를 통해 외부 파일을 불러오는 방식입니다.

내부 스타일 시트 (Internal Style Sheet)

단일 페이지 웹사이트나 간단한 테스트 프로젝트를 작성할 때 유용하게 쓰입니다.

작성법 예시

HTML 문서 상단 <head> 태그 내에 작성합니다.

<head>
    <style>
        body {
            background-color: #0f172a;
            color: #f8fafc;
        }
        h1 {
            color: #38bdf8;
        }
    </style>
</head>

외부 스타일 시트 (External Style Sheet)

실무 환경에서 가장 보편적이고 표준적인 CSS 작성 방식입니다.

STEP 01

1. CSS 파일 생성

독립된 style.css 파일을 만들고 스타일 규칙을 입력합니다.

/* style.css */
body {
    background-color: #0f172a;
}
p {
    color: #94a3b8;
}
STEP 02

2. HTML 연동

HTML 문서의 <head> 영역에서 <link> 태그로 불러옵니다.

<head>
    <link rel="stylesheet" href="style.css">
</head>

특징 및 비교 분석

상황에 맞는 최선의 방식을 선택하여 효율적인 개발 환경을 구축하세요.

구분 내부 스타일 시트 외부 스타일 시트
파일 구조 HTML 파일 내부에 포함 (단일 파일) HTML 파일과 CSS 파일 분리 (다중 파일)
유지보수성 페이지가 많아질수록 수정이 어려움 하나의 CSS 파일로 여러 웹페이지 일괄 제어 가능
로딩 속도 파일 재사용 불가 (매 페이지마다 코드 재로드) 브라우저 캐싱 기능 활용으로 성능 최적화 가능
권장 사용 환경 단일 페이지, 이메일 템플릿, 빠른 프로토타이핑 다중 페이지 사이트, 대규모 실무 프로젝트 (표준 방식)

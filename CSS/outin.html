CSS 적용 방식 3가지

HTML 문서에 디자인 스타일을 적용하는 대표적인 방식인 **외부, 내부, 인라인 스타일 시트**의 특성과 올바른 활용법을 설명합니다.

TYPE 01

외부 스타일 시트

독립된 .css 파일에 스타일을 작성하고 <link> 태그로 연동하는 방식입니다.

TYPE 02

내부 스타일 시트

HTML 문서 내 <head> 영역의 <style> 태그 안에 작성하는 방식입니다.

TYPE 03

인라인 스타일

HTML 요소의 style 속성에 직접 스타일 규칙을 추가하는 방식입니다.

외부 스타일 시트 (External Style Sheet)

실무 프로젝트에서 가장 널리 쓰이며 추천되는 표준 방식입니다.

STEP 01

1. CSS 파일 작성

독립된 파일(예: style.css)을 작성합니다.

/* style.css */
body {
    background-color: #0f172a;
    color: #f8fafc;
}
h1 {
    color: #38bdf8;
}
STEP 02

2. HTML 파일 연동

HTML의 <head> 영역에 <link>를 추가합니다.

<head>
    <link rel="stylesheet" href="style.css">
</head>

내부 스타일 시트 (Internal Style Sheet)

단일 페이지나 빠른 프로토타입 작성 시에 유용하게 사용됩니다.

작성 구조 예시

HTML 파일 상단의 <head> 내부 <style> 태그 안에 배치합니다.

<head>
    <style>
        .card {
            background-color: #1e293b;
            border-radius: 20px;
            padding: 30px;
        }
    </style>
</head>

인라인 스타일 시트 (Inline Style)

특정 개별 요소에 가장 높은 우선순위로 일회성 스타일을 적용할 때 사용됩니다.

작성 구조 예시

태그 내 style="..." 속성을 써서 속성과 값을 직접 지정합니다.

<h1 style="color: #38bdf8; font-size: 2rem;">
    인라인 스타일이 적용된 제목
</h1>
<p style="margin-bottom: 10px;">
    개별 태그에 즉각 스타일이 설정됩니다.
</p>

required & pattern 속성

별도의 JavaScript 코드 없이, HTML5 표준 속성만으로 구현하는 클라이언트 사이드 데이터 검증 시스템

required Boolean

폼을 제출하기 전, 사용자가 반드시 값을 입력하거나 선택해야 하는 필수 필드로 지정합니다. 값을 비워둔 채 폼을 제출하려고 하면 브라우저 자체 경고 메시지가 발생합니다.

<input type="text" required>
pattern String (RegEx)

입력받은 값이 올바른 형식인지 검증하기 위해 정규 표현식(Regular Expression)을 지정합니다. 사용자가 입력한 내용이 이 패턴과 매치되지 않으면 제출이 차단됩니다.

<input pattern="[A-Za-z]{3,}">

Cascading Style Sheets 3

CSS3는 웹 문서의 스타일을 정의하는 표준 기술의 세 번째 메이저 버전입니다. 모듈화를 통해 독립적으로 발전하며 현대적이고 역동적인 웹 브라우징 환경을 구축합니다.

하위 호환성 유지

CSS3는 이전 CSS 버전과 완벽하게 호환되므로 기존 웹사이트를 깨뜨리지 않고 새로운 핵심 기능을 점진적으로 도입할 수 있습니다.

모듈러 시스템

전체가 하나의 표준안이었던 과거와 달리, 선택자, 컬러, 박스 모델 등 각 기능이 독립된 모듈로 분리되어 개별적으로 업데이트됩니다.

화려한 그래픽 효과

별도의 이미지 파일이나 자바스크립트 없이도 그라디언트, 그림자, 테두리 둥글기, 3D 변형 등을 브라우저 자체적으로 렌더링합니다.

핵심 기능 알아보기

Selectors & Box Model

원하는 요소를 정확히 타겟팅하고 크기를 다루는 방식이 대폭 강화되었습니다.

고급 선택자 (Selectors)

구조적 가상 클래스를 통해 자바스크립트 없이 특정 순서나 상태의 요소를 정확히 스타일링합니다.

li:nth-child(odd) {
  background: #1e293b;
}

박스 사이징 (Box-sizing)

테두리와 안쪽 여백(Padding)을 전체 너비에 포함시켜 복잡한 레이아웃 계산 문제를 깔끔하게 해결합니다.

* {
  box-sizing: border-box;
}

유연한 색상과 투명도

RGBA와 HSLA를 지원하여 배경이나 텍스트의 불투명도(Alpha)를 자식 요소에 영향을 주지 않고 개별 조절합니다.

.modal {
  background: rgba(0,0,0,0.5);
}

Modern Layout System

Float과 Position의 한계를 넘어 스크린 크기에 반응하는 강력한 2차원 공간 배치 스타일을 제공합니다.

플렉스박스 (Flexbox)

1차원(행 또는 열) 레이아웃을 위한 기능으로, 정렬 및 요소를 조절하여 반응형 UI 컴포넌트를 만들 때 최적의 효율을 보여줍니다.

.flex-container {
  display: flex;
  justify-content: center;
}

그리드 시스템 (Grid)

2차원(가로와 세로) 격자 기반 레이아웃을 생성합니다. 페이지 전체의 거시적인 구조 디자인을 설계하는 데 완벽히 특화되어 있습니다.

.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

Effects & Animation

정적인 문서에 생동감을 불어넣어 사용자 경험(UX)을 극대화시키는 시각 효과 모듈입니다.

트랜지션 (Transitions)

스타일 값이 변경될 때(예: 마우스 오버) 일정 시간에 걸쳐 부드럽고 자연스럽게 변화 과정을 연출합니다.

.button {
  transition: all 0.3s ease;
}

키프레임 애니메이션

자바스크립트 도움 없이 웹 요소의 정밀한 상태 변화 타임라인을 정의하여 복잡한 움직임을 제어합니다.

@keyframes fade {
  from { opacity: 0; }
  to { opacity: 1; }
}

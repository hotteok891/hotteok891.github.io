CSS3 선택자(Selector) 가이드

웹 페이지의 요소를 정확하게 타겟팅하는 핵심 방법

1. 기본 선택자 (Basic Selectors)

가장 자주 쓰이는 CSS의 뼈대가 되는 선택자입니다.

선택자 이름 문법 설명
전체 선택자 * 페이지의 모든 요소를 선택합니다.
태그 선택자 div, p 지정한 태그명을 가진 모든 요소를 선택합니다.
클래스 선택자 .className 특정 클래스 속성을 가진 요소를 선택합니다. (중복 가능)
아이디 선택자 #idName 고유한 특정 아이디 속성을 가진 요소를 선택합니다. (페이지 내 단 하나)

2. 복합 선택자 (Combinators)

요소 간의 관계(부모, 자식, 형제)를 이용하여 선택합니다.

선택자 이름 문법 설명
하위(자손) 선택자 div p div 내부에 있는 모든 p 요소를 선택합니다. (공백 기준)
자식 선택자 div > p div 바로 한 단계 아래에 있는 자식 p 요소만 선택합니다.
인접 형제 선택자 h1 + p h1 바로 뒤에 오는 첫 번째 형제 p 요소만 선택합니다.
일반 형제 선택자 h1 ~ p h1 뒤에 오는 모든 형제 p 요소를 선택합니다.

3. 가상 클래스 선택자 (Pseudo-Classes)

CSS3에서 대폭 강화된 기능으로, 요소의 특정 상태나 위치를 타겟팅합니다.

동적 가상 클래스

:hover 요소에 마우스 커서를 올렸을 때 적용됩니다.
:focus input 창처럼 요소를 클릭하여 초점이 맞춰졌을 때 적용됩니다.

구조적 가상 클래스 (CSS3 핵심)

:first-child 부모의 형제 요소 중 첫 번째 자식인 요소를 선택합니다.
:last-child 부모의 형제 요소 중 마지막 자식인 요소를 선택합니다.
:nth-child(n) 부모의 n번째 자식 요소를 선택합니다. (예: :nth-child(2n)은 짝수 번째)

4. 실제 사용 예시 (Example)

HTML과 CSS를 결합하여 아래와 같이 활용할 수 있습니다.

/* 클래스명이 'menu'인 요소 안의 모든 li 중 짝수 번째만 배경색 변경 */
.menu li:nth-child(2n) {
    background-color: #f0f0f0;
}

/* 버튼에 마우스를 올렸을 때 포인터 바꾸고 투명도 조절 */
.btn:hover {
    cursor: pointer;
    opacity: 0.8;
}

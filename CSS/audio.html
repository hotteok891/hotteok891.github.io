<audio> 태그

플러그인 없이 웹페이지 내에 음성 파일이나 음악 스트리밍을 직접 삽입하고 제어하는 표준 멀티미디어 요소

controls 속성

재생/일시정지, 재생 바, 음량 조절 등 브라우저 기본 오디오 컨트롤 인터페이스를 화면에 표시합니다.

autoplay 속성

오디오 파일 로드가 완료되면 유저가 재생을 누르지 않아도 자동으로 음악을 재생합니다. (브라우저 정책상 대부분 muted와 함께 켜야 작동합니다.)

loop 속성

오디오 재생이 끝까지 도달했을 때 멈추지 않고, 처음부터 다시 무한 반복하여 재생하도록 설정합니다.

muted 속성

오디오를 처음 시작할 때 음소거 상태로 시작합니다. 미디어의 자동 재생 정책 우회를 위해 주로 세트로 사용됩니다.

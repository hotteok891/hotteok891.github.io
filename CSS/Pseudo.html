Pseudo-selectors

HTML 문서 구조에 직접 나타나지 않는 요소의 특수한 상태(State)나 특정 영역을 선택하여 스타일을 부여하는 CSS 선택자입니다.

의사 클래스 (Pseudo-classes)

콜론 하나(:)를 사용하며, 요소의 마우스 호버, 포커스, 순서 등 동적인 상태를 정의합니다.

상태 지정 (:hover / :focus)

사용자 상호작용에 반응하여 마우스를 올리거나 포커스가 맞춰졌을 때 스타일을 변경합니다.

.button:hover {
  background-color: #38bdf8;
  cursor: pointer;
}

구조적 선택 (:nth-child)

부모 요소 내 자식 요소들의 순서나 규칙(홀수/짝수 등)에 맞춰 특정 요소를 선택합니다.

li:nth-child(2n) {
  background-color: #1e293b;
}

의사 요소 (Pseudo-elements)

이중 콜론(::)을 사용하며, 요소의 특정 부분(앞/뒤 공간, 첫 글자 등)에 가상 콘텐츠를 생성하거나 지정합니다.

가상 콘텐츠 삽입 (::before / ::after)

HTML 태그를 직접 수정하지 않고 CSS를 통해 요소의 전후에 내용이나 디자인 요소를 추가합니다.

.card::before {
  content: "★ ";
  color: #f59e0b;
}

텍스트 영역 선택 (::selection)

사용자가 드래그하여 선택한 문서 텍스트의 배경색 및 글자 색상을 커스텀 지정합니다.

::selection {
  background-color: #38bdf8;
  color: #0f172a;
}

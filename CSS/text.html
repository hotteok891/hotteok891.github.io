Fonts & Typography

웹 페이지의 가독성과 분위기를 결정짓는 핵심 스타일 요소로, 글꼴 종류·두께·크기부터 정렬·간격까지 제어합니다.

주요 폰트 (Font) 속성

글꼴의 외형적 특징과 크기, 두께 등을 지정하는 속성입니다.

글꼴 및 크기 지정

font-family로 우선순위 서체를 지정하고 font-size로 크기를 설정합니다.

body {
  font-family: 'Pretendard', sans-serif;
  font-size: 16px;
}

두께 및 스타일 지정

font-weight로 글자 두께를 수치(100~900)나 키워드로 설정합니다.

.title {
  font-weight: 700;
  font-style: italic;
}

주요 텍스트 (Text) 속성

문단 정렬, 행간, 자간, 색상 등 글자 배치를 정밀하게 다룹니다.

정렬 및 행간

text-align으로 정렬을 조정하고 line-height로 줄 간격을 조절합니다.

p {
  text-align: center;
  line-height: 1.6;
}

자간 및 장식

letter-spacing으로 글자 간격을 조절하고 text-decoration으로 밑줄 등을 제어합니다.

a {
  letter-spacing: 1px;
  text-decoration: none;
}

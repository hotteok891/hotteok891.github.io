ol vs ul 목록 태그

데이터의 성격에 따라 순차적 번호(Order)를 부여하거나 독립적 불릿(Unorder) 기호로 구조화하는 표준 리스트 요소

<ol> Ordered List

순서가 유의미한 항목 목록을 생성할 때 사용합니다. 브라우저가 자동으로 항목 앞에 숫자(1, 2, 3)나 알파벳, 로마자 마커를 부여합니다. 각 내부 항목은 반드시 <li> 태그로 감싸야 합니다.

<ol>
    <li>첫 번째 단계</li>
    <li>두 번째 단계</li>
</ol>
<ul> Unordered List

순서가 바뀌어도 상관없는 단순 나열식 목록을 정의합니다. 기본적으로 정원형(Disc) 불릿 기호가 마커로 붙습니다. 네비게이션 메뉴바(GNB)나 카드 리스트 등을 구조화할 때 실무에서 가장 기본이 되는 태그입니다.

<ul>
    <li>사과</li>
    <li>바나나</li>
</ul>

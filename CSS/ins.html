Font & Typography

font-family: 'Pretendard';
font-size: 2rem;
font-weight: 700;

가독성이 뛰어난 Pretendard 폰트를 사용하고 700(Bold) 굵기를 적용하여 텍스트의 시각적 위계를 강조했습니다.

Gradient Text Effect

background: linear-gradient(...);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;

배경에 그래디언트를 적용한 뒤 텍스트 영역에만 채워지도록 설정하여 트렌디한 네온 그래디언트 텍스트 효과를 연출했습니다.

Glow & Transition

text-shadow: 0 0 12px ...;
transition: all 0.3s ease;

마우스 호버 시 은은한 광원(Glow) 효과가 나타나도록 text-shadow를 지정하고 0.3초 부드러운 전환 효과를 부여했습니다.

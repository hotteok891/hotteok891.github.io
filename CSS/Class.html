Class Selector

HTML 요소의 class 속성을 사용하여 특정 그룹의 요소들에 동일한 스타일을 재사용 가능하게 적용하는 CSS 선택자입니다.

기본 문법과 특징

클래스 이름 앞에 마침표(.)를 붙여 지정합니다.

재사용성 (Reusability)

동일한 클래스 이름을 여러 HTML 요소에 중복 부여하여 그룹 스타일링을 구현할 수 있습니다.

.btn-primary {
  background-color: #38bdf8;
  color: #0f172a;
}

다중 클래스 적용

공백으로 구분하여 한 요소에 여러 개의 클래스를 동시에 지정할 수 있어 유연합니다.

<button class="btn active">
  전송
</button>

주요 사용 예시

웹 페이지 컴포넌트의 공통 스타일 및 상태를 정의할 때 주로 사용됩니다.

HTML 적용 예시

서로 다른 태그 요소라도 class="card"를 지정하여 동일 그룹화가 가능합니다.

<div class="card">카드 1</div>
<article class="card">카드 2</article>

CSS 스타일링 예시

.card 클래스가 포함된 모든 요소의 테두리와 여백을 일괄 적용합니다.

.card {
  padding: 30px;
  border-radius: 20px;
  border: 1px solid #334155;
}

ID Selector

HTML 요소의 id 속성을 이용하여 특정 단 하나의 요소를 정확하게 선택하는 CSS 선택자입니다.

기본 문법과 특징

아이디 이름 앞에 샵 기호(#)를 붙여서 표기합니다.

유일성 (Uniqueness)

id는 웹 페이지 내에서 오직 하나만 존재해야 하는 고유한 식별자입니다.

#header {
  background-color: #1e293b;
}

높은 명시도 (Specificity)

태그 선택자나 클래스 선택자보다 명시도 점수가 높아 우선순위 적용에 강력합니다.

#main-logo {
  width: 200px;
}

주요 사용 예시

페이지 내 유일한 주요 레이아웃이나 요소 지정 시 주로 사용됩니다.

HTML 적용 예시

태그 속성에 id="header" 형태로 고유한 이름을 부여합니다.

<header id="header">
  <h1>Logo</h1>
</header>

CSS 스타일링 예시

#header 스타일을 통해 해당 구역만의 전용 스타일을 정의합니다.

#header {
  height: 80px;
  border-bottom: 1px solid #334155;
}

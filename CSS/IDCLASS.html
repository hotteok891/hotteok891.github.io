ID & CLASS Selector

CSS 선택자 중 가장 빈번하게 사용되는 두 가지 핵심 선택자로, 요소의 단일 고유성(ID)과 그룹 재사용성(Class)을 정의합니다.

핵심 차이점 비교

상황과 목적에 맞춰 적절한 선택자를 사용하는 것이 올바른 웹 표준 구현의 시작입니다.

ID 선택자 (#id)

페이지 내에서 오직 단 하나만 존재하는 요소에 지정합니다. 명시도(우선순위)가 매우 높습니다.

/* 기호: # */
#main-header {
  background-color: #1e293b;
}

CLASS 선택자 (.class)

페이지 내 여러 요소에 중복 적용할 스타일 그룹에 지정합니다. 다중 클래스 부여가 가능합니다.

/* 기호: . */
.card-title {
  color: #38bdf8;
}

실전 HTML & CSS 코드

ID와 CLASS를 함께 조화롭게 구성하는 기본 예시입니다.

HTML 구조 예시

최상위 레이아웃에는 id를, 반복되는 카드 및 컴포넌트에는 class를 부여합니다.

<header id="site-header">
  <h1 class="title primary">Logo</h1>
</header>

CSS 스타일링 예시

ID 선택자로 고유 레이아웃을 잡고, Class 선택자로 공통 폰트 및 스타일을 처리합니다.

#site-header {
  height: 80px;
}

.title {
  font-size: 2rem;
}

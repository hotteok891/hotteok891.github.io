Web Component

<input> Tag

사용자로부터 데이터를 입력받기 위해 사용하는 HTML의 가장 강력하고 다재다능한 폼(Form) 요소입니다. 종료 태그가 없는 빈 태그(Empty Tag)로 동작합니다.

다양한 데이터 타입

간단한 텍스트 입력부터 패스워드, 날짜, 체크박스, 파일 업로드 등 다양한 형태의 UI와 데이터 유형을 단 하나의 태그로 모두 처리할 수 있습니다.

빈 태그 (Empty Tag)

</input>과 같은 닫는 태그를 가지지 않습니다. 오직 자체 속성(Attributes)만을 사용하여 브라우저에 렌더링할 형태와 데이터를 규정합니다.

서버 데이터 전송

name 속성과 value 속성을 결합하여 사용자가 입력한 데이터를 서버(Back-end) 시스템으로 구조화하여 전송하는 핵심 창구 역할을 담당합니다.

Configuration

핵심 속성 (Attributes)

input 태그의 동작 방식과 제약 조건을 제어하는 가장 대표적인 4가지 필수 속성입니다.

type

입력받을 컨트롤의 종류를 정의합니다. text, password, email, checkbox 등이 있으며 생략할 경우 기본값은 text로 지정됩니다.

name

폼(Form)이 제출될 때, 입력된 값을 서버로 전송하기 위한 '변수명(Key)' 역할을 합니다. 서버 통신을 위해 반드시 지정해야 합니다.

value

입력 필드의 초기값(Default Value)을 지정합니다. 사용자가 값을 입력하면 이 속성에 바인딩되어 최종적으로 전송될 데이터가 됩니다.

placeholder

사용자가 값을 입력하기 전, 필드에 옅은 회색으로 보여주는 '입력 힌트 메시지'입니다. 값을 입력하기 시작하면 자동으로 사라집니다.

Type Variations

다양한 유형 코드 예시

type 속성값의 변경만으로 브라우저가 제공하는 UI 기능을 완전히 바꿀 수 있습니다.

일반 텍스트 & 패스워드

<input type="text" placeholder="아이디">
<input type="password">

가장 범용적인 텍스트 입력창과 입력 내용이 암호화 기호(●)로 숨겨져 출력되는 비밀번호 전용 입력창입니다.

선택형 버튼 (Checkbox & Radio)

<input type="checkbox" checked>
<input type="radio" name="gender">

다중 선택이 가능한 체크박스 유형과, 동일한 name 그룹 내에서 단 하나만 선택 가능한 라디오 버튼 유형입니다.

기타 확장 기능 (Color & Date)

<input type="date">
<input type="color">

브라우저 자체 캘린더 UI를 팝업하여 날짜를 선택하게 하거나, 운영체제 기본 컬러 피커를 호출하는 고도화된 유형입니다.

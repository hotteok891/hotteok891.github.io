Type Selector

HTML 태그 이름을 직접 지정하여 해당 문서 내의 모든 요소에 동일한 스타일을 적용하는 CSS의 가장 기본적이고 강력한 선택자입니다.

기본 문법과 특징

별도의 기호(. 또는 #) 없이 HTML 태그명 자체를 사용합니다.

직관적인 지정

태그 이름을 그대로 사용하여 문서 내의 해당 모든 태그 요소를 빠르게 선택할 수 있습니다.

p {
  color: #f8fafc;
}

전역 기본값 설정

사이트 전체에서 쓰이는 글꼴, 여백, 기본 색상 등 글로벌 스타일 기준을 잡을 때 적합합니다.

body {
  font-family: 'Pretendard';
}

주요 사용 예시

타입 선택자를 활용한 일괄 스타일 변경 케이스입니다.

제목(Header) 스타일 통일

문서 내의 모든 <h1> 요소의 크기와 색상을 한 번에 지정할 수 있습니다.

h1 {
  font-size: 3.5rem;
  color: #38bdf8;
}

목록(List) 기호 제거

웹 사이트 내 모든 <ul> 요소의 기본 불릿(bullet) 기호를 일괄 제거합니다.

ul {
  list-style: none;
}

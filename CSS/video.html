<video> 태그

플러그인 없이 웹페이지 내에 독립적인 동영상 플레이어를 빌드하고 미디어를 제어하는 가상 요소

controls / autoplay 기본

재생 컨트롤 바를 노출하며, 오디오와 마찬가지로 미디어 로드 완료 후 자동 재생을 지시할 수 있습니다.

loop / muted 제어

영상을 무한 반복 재생 상태로 고정하거나 초기 사운드를 음소거합니다. 웹 배경 영상을 빌드할 때 주로 필수로 선언됩니다.

poster 썸네일

영상이 다운로드되거나 사용자가 재생 버튼을 누르기 전까지 플레이어 화면에 띄워둘 대표 썸네일 이미지 경로를 지정합니다.

playsinline 모바일 기기

iOS/Android 브라우저에서 동영상 재생 시, 운영체제 기본 플레이어가 강제로 전체화면을 뺏어가는 것을 막고 웹페이지 프레임 내에서 재생되도록 만듭니다.

Paragraph & Text Elements

웹페이지에서 가장 기본이 되는 텍스트 컴포넌트인 <p> 태그와 <span> 태그를 다룹니다. 두 태그의 구조적 특징과 렌더링 방식의 차이를 심층적으로 이해할 수 있습니다.

텍스트 태그 핵심 분석

블록 레벨 요소와 인라인 레벨 요소의 대표적인 두 태그의 성격을 직관적으로 확인하세요.

<p> : Paragraph

단락 생성 블록 요소

하나의 독립된 문단(Paragraph)을 정의합니다. 블록(Block) 레벨 특성을 가져 항상 새로운 줄에서 시작하고, 가로 전체 너비를 차지하며, 위아래로 브라우저 기본 여백(Margin)이 자동으로 생성됩니다.

Visual Block Area (영역 시각화)
첫 번째 문단 (<p>)입니다.
두 번째 문단입니다. 자동으로 줄바꿈됩니다.
<span> : Inline Wrapper

텍스트 내부 인라인 요소

문장 안의 특정 단어나 일부 텍스트에만 스타일 혹은 자바스크립트 효과를 부여할 때 사용합니다. 인라인(Inline) 레벨 요소로 줄바꿈 없이 필요한 만큼의 너비만 차지하며, 본문의 흐름을 깨지 않습니다.

Visual Inline Area (영역 시각화)
문장 속에서 특정 단어 부분만 선택하여 강조하거나 스타일을 변경할 때 유용합니다.

속성 및 차이점 완벽 비교

두 태그의 디스플레이 타입과 레이아웃 배치 원칙 메커니즘 체계입니다.

■ Display 속성의 차이점
구분 <p> 태그 <span> 태그
기본 디스플레이 display: block; display: inline;
줄바꿈 여부 항상 새로운 줄에서 시작 줄바꿈 없이 우측으로 나열
너비 / 높이 설정 width, height 지정 가능 width, height 지정 불가능
상하 마진 (Margin) 적용 가능 (기본값 존재) 적용 불가능 (좌우만 가능)
■ 올바른 중첩 규칙 (Semantic Rule)

• 허용 구조: <p>텍스트 내용 <span>강조</span> 텍스트</p> (블록 내부 인라인 배치)

• 금지 구조: <span>내부에 <p>태그를</p> 넣는 행위</span> (웹 표준에 어긋남)

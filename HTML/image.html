Image Element System

HTML 웹 문서에 시각적 에셋을 삽입하는 기본 빈(Void) 엘리먼트인 <img> 태그의 동작 원리를 파악합니다. 모던 반응형 웹에서 이미지가 깨지지 않고 최적화되는 구조적 설계를 학습합니다.

웹 이미지 렌더링 필수 속성

이미지를 불러오는 경로 지정과 웹 접근성을 위한 대체 텍스트 구성 요소입니다.

src="경로" & alt="설명"

경로 정의와 대체 텍스트

자식 태그가 없는 빈 태그(Empty tag)입니다. src는 로컬 파일이나 웹 상의 이미지 주소(URL)를 연결하며, alt는 이미지를 로드하지 못했을 때나 시각 장애인용 스크린 리더가 읽을 대체 설명을 매핑합니다.

표준 <img> 구조 렌더링
max-width: 100%

유동형 반응형 이미지 제어

이미지는 고유의 원본 크기(정적 폭)를 가집니다. 부모 컨테이너의 크기가 이미지보다 작아질 때 레이아웃이 터지는 현상을 막기 위해, CSS로 max-width: 100%; height: auto; 구조를 기본 탑재하는 것이 모던 UI의 정석 패턴입니다.

컨테이너 폭에 자동 동기화

CSS 가로세로 비율 최적화 (object-fit)

지정된 고정 크기 박스 안에서 이미지가 일그러지거나 찌그러지지 않도록 크롭(Crop) 및 스케일링하는 메커니즘입니다.

Object-Fit Rendering Mode Comparison

동일한 비율(가로세로 고정 박스) 하에서 두 속성이 원본 이미지를 어떻게 변형하는지 비교합니다.

1. object-fit: cover

가로세로 비율을 유지하면서 박스를 가득 채웁니다. 남는 부분은 잘려나갑니다(대시보드 썸네일용).

2. object-fit: contain

이미지가 잘리지 않도록 원본 비율을 온전히 보존하면서 박스 내부에 맞춥니다. 빈 공간이 생깁니다.

⚠️ 검색엔진 및 성능 최적화(SEO) 필수 가이드

  • 1. 의무적인 alt 속성 부여: 의미가 없는 장식용 그래픽 이미지일지라도 alt=""와 같이 빈 값을 명시해 주어야 스크린 리더가 불필요한 파일명을 읽는 오작동을 피할 수 있습니다.
  • 2. 레이아웃 이동(CLS) 방지: 모던 브라우저 엔진의 렌더링 최적화를 위해 HTML 자체에 width와 height 원본 비율 수치를 픽셀 단위로 선언해 두면, 이미지가 로드되기 전 레이아웃 영역이 확보되어 화면이 덜컹거리는 현상(CLS)을 완벽히 방지할 수 있습니다.

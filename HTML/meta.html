<META /> METADATA TAG

<meta> 태그 완벽 가이드

브라우저와 검색엔진, 소셜 미디어에게 웹페이지의 정보를 보이지 않게 전달하는 메타데이터 정의 태그입니다.

🛠️ 필수 기본 설정 (기기 및 인코딩)

웹페이지를 만들 때 가장 기본이 되는 필수 설정입니다. 글자 깨짐을 방지하는 charset 설정과 모바일 화면 대응을 위한 반응형 뷰포트(viewport) 설정을 담당합니다. 항상 <head>의 최상단에 배치하는 것이 좋습니다. 

<!-- 문자 인코딩 설정 (UTF-8 필수) -->
<meta charset="UTF-8">

<!-- 모바일 반응형 뷰포트 설정 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

🔍 검색엔진 최적화 (SEO Meta)

네이버, 구글 등 검색엔진 로봇이 내 웹사이트를 읽어갈 때 참고하는 정보입니다. 검색 결과 화면에 노출될 description(페이지 요약 설명)과 keywords(핵심 키워드)를 입력하여 검색 노출 품질을 향상시킵니다. 

<!-- 검색 결과에 나타날 웹사이트 설명 -->
<meta name="description" content="모던한 대시보드 스타일의 HTML 태그 가이드 사이트입니다.">

<!-- 웹페이지 핵심 키워드 -->
<meta name="keywords" content="HTML, meta태그, 웹개발, 웹퍼블리싱">

💬 오픈 그래프 (Open Graph / SNS용 메타 태그)

카카오톡, 페이스북, 디스코드 등에 웹사이트 링크를 보냈을 때, 미리보기 박스에 나타나는 **제목, 설명, 썸네일 이미지**를 제어하는 메타 태그입니다. 페이스북이 개발한 프로토콜이며 속성명 앞에 og: 프로퍼티를 붙여 구별합니다. 

<!-- 카카오톡/페이스북 링크 공유 시 보여줄 메타 데이터 -->
<meta property="og:type" content="website">
<meta property="og:title" content="HTML 태그 사전 - 메타태그 편">
<meta property="og:description" content="링크를 공유했을 때 나타나는 상세 설명입니다.">
<meta property="og:image" content="https://example.com/thumbnail.jpg">
<meta property="og:url" content="https://example.com/main">

📊 meta 태그의 핵심 특징

1. **빈 태그(Empty Tag):** 닫는 태그(``)가 존재하지 않는 단독 태그입니다.
2. **위치:** 반드시 문서의 정보 구역인 <head> ... </head> 영역 내부에 위치해야 합니다.
3. **속성 기반 구조:** 태그 자체로는 아무 의미도 없으며, name / property 속성으로 정보의 종류를 정하고, content 속성으로 실제 데이터 값을 담는 방식으로 동작합니다.

<meta> 태그

메타데이터(Metadata)를 정의할 때 사용하는 태그입니다. 브라우저 화면에 직접 표시되지는 않지만 검색 엔진 최전선에서의 SEO 최적화, 웹페이지의 인코딩 설정, 뷰포트 관리 등 핵심적인 기저 설정을 담당합니다.

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>

주요 활용 방식

meta 태그는 속성의 조합에 따라 웹사이트의 성격을 다양하게 규정합니다.

문자 인코딩 설정

웹 문서의 텍스트가 깨지지 않고 올바르게 렌더링되도록 문서 인코딩 형식을 지정합니다. 전 세계적인 표준인 UTF-8이 주로 사용됩니다.

<meta charset="UTF-8">

반응형 뷰포트 제어

모바일, 태블릿 등 다양한 모바일 기기 화면 비율에 맞춰 사이트 크기와 스케일을 조절하는 선언입니다.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

검색 엔진 최적화 (SEO)

검색 엔진 로봇에게 웹페이지의 핵심 설명(Description)이나 키워드를 전달하여 검색 노출 결과에 반영되도록 유도합니다.

<meta name="description" content="AI 기반 대시보드 설명...">

오픈 그래프 (Open Graph)

카카오톡, 디스코드, 페이스북 등 소셜 미디어로 웹페이지 링크가 공유될 때 표시될 미리보기 제목, 이미지, 설명을 지정합니다.

<meta property="og:title" content="Dashboard">

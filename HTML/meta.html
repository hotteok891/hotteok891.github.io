HTML <meta> 태그 완벽 가이드

브라우저와 검색엔진에게 웹사이트의 정보를 전달하는 숨은 공신

1. 메타(meta) 태그란?

<meta> 태그는 웹 페이지에 직접적으로 보이지 않는 '메타데이터(Metadata, 데이터에 대한 데이터)'를 정의할 때 사용합니다.

이 태그는 항상 HTML 문서의 <head> 태그 내부에 위치하며, 브라우저, 검색엔진(SEO), SNS 공유 시스템 등이 웹페이지를 읽는 기준이 됩니다.

2. 가장 자주 쓰는 핵심 메타 태그 4가지

① 문자 인코딩 설정

웹 화면에서 글자가 깨지지 않도록 전 세계 언어를 지원하는 UTF-8로 설정합니다.

<meta charset="UTF-8">
② 뷰포트(Viewport) 설정

스마트폰, 태블릿 등 모바일 기기 화면 크기에 맞게 사이트가 자동으로 조절되도록 합니다. (반응형 웹 필수)

<meta name="viewport" content="width=device-width, initial-scale=1.0">
③ 검색엔진 설명 (SEO)

네이버나 구글 같은 검색엔진 결과 창에 보여줄 사이트 요약 문구를 지정합니다.

<meta name="description" content="웹 퍼블리싱 강의 사이트입니다.">
④ 오픈 그래프 (Open Graph)

카카오톡이나 페이스북에 링크를 공유했을 때 뜨는 제목, 설명, 이미지를 제어합니다.

<meta property="og:title" content="내 사이트 제목">
<meta property="og:image" content="thumb.jpg">

3. 메타 태그의 주요 특징

• 닫는 태그가 없음: <meta> 태그는 내용을 감싸는 형태가 아니라 속성만 가질 수 있는 빈 태그(Empty tag)이므로 </meta>로 닫지 않습니다.

• 속성 중심 구조: 주로 name과 content 쌍을 사용하거나, 문자셋을 뜻하는 charset, SNS 공유를 위한 property 속성을 사용합니다.

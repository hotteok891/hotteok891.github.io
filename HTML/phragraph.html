HTML 태그 백과사전

줄 바꿈을 담당하는 핵심 태그, 완벽하게 이해하기

1. <p> 태ag (Paragraph)

Paragraph(단락)의 약자로, 본문의 하나의 문단을 정의할 때 사용합니다.

  • 특징: 태그가 끝마쳐지면 자동으로 위아래에 약간의 여백(Margin)이 생깁니다.
  • 성격: 블록 레벨 요소 (Block-level element) - 화면 전체 너비를 차지합니다.
  • 닫는 태그: 필수 </p>

💻 코드 예시

<p>첫 번째 문단입니다. 내용이 길어지면 자동으로 줄바꿈이 됩니다.</p>
<p>두 번째 문단입니다. 위 문단과 일정한 간격이 벌어집니다.</p>
👀 실제 화면 출력

첫 번째 문단입니다. 내용이 길어지면 자동으로 줄바꿈이 됩니다.

두 번째 문단입니다. 위 문단과 일정한 간격이 벌어집니다.

2. <br> 태그 (Break)

Line Break(줄 바꿈)의 약자로, 문단 안에서 강제로 줄을 바꿀 때 사용합니다.

  • 특징: 위아래 여백 없이, 단순히 텍스트만 바로 다음 줄로 내립니다.
  • 성격: 빈 태그 (Empty element) - 콘텐츠가 없고 형태만 바꿉니다.
  • 닫는 태그: 없음 (단독 사용) 또는 <br />

💻 코드 예시

<p>안녕하세요.<br>반갑습니다.<br>여기는 같은 문단 안입니다.</p>
👀 실제 화면 출력

안녕하세요.
반갑습니다.
여기는 같은 문단 안입니다.

💡 핵심 차이점 요약

구분 <p> 태그 <br> 태그
목적 새로운 하나의 문단을 만들 때 문단 내에서 줄만 바꾸고 싶을 때
여백(Margin) 위아래에 자동으로 공백이 생김 공백 없이 줄바꿈만 일어남
태그 형태 쌍을 이루는 태그 (<p>...</p>) 닫는 태그가 없는 단독 태그 (<br>)
주의사항 단순히 줄을 여러 번 띄우기 위해 남용하면 안 됨 문단 간격을 넓히는 용도로 여러 번 쓰지 말 것 (CSS 권장)

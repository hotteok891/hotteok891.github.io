Table Grid Cell Merging

HTML 테이블 엘리먼트(<td>, <th>)의 셀들을 가로나 세로 방향으로 합치는 기초 원리를 다룹니다. 격자 구조의 레이아웃을 흐트러뜨리지 않고 제어하는 핵심 메커니즘을 알아봅니다.

기초 핵심 속성 제어

가로 합치기(colspan)와 세로 합치기(rowspan)는 설정한 숫자만큼 칸을 '확장'하는 개념입니다.

colspan="숫자"

가로 셀 병합 (Column Span)

열(Column)을 합치는 속성입니다. 좌측에서 우측 방향으로 지정된 수만큼 셀을 병합하여 확장합니다. 합쳐진 개수만큼 해당 행(<tr>) 내의 다른 셀 코드(<td>)를 제거해 주어야 테이블 구조가 깨지지 않습니다.

Colspan="2" 적용 예시
1행 1열 + 2열 합침 1행 3열
2행 1열 2행 2열 2행 3열
rowspan="숫자"

세로 셀 병합 (Row Span)

행(Row)을 합치는 속성입니다. 위에서 아래 방향으로 지정된 수만큼 셀을 확장합니다. 세로로 합쳐진 만큼, 그 아래행들의 동일한 위치에 들어갈 셀 코드를 미리 삭제해 주어야 아래행이 우측으로 밀리는 현상을 막을 수 있습니다.

Rowspan="2" 적용 예시
1행 1열 +
2행 1열 합침		 1행 2열 1행 3열
2행 2열 2행 3열

종합 레이아웃 응용 렌더링

colspan과 rowspan이 복합적으로 적용된 주간 정산 리포트 형식의 실습 테이블입니다.

⚠️ 셀 병합 설계 시 절대 규칙

  • 1. 코드 카운트 매칭: 테이블의 기본 레이아웃이 4열 구조라면, 어떤 행이든 td 개수 + colspan 확장 보너스값의 합이 반드시 4가 되어야 합니다.
  • 2. 아래행 삭제 법칙: 상위 행에서 rowspan="3"을 선언했다면, 그 바로 밑에 따라오는 2개 행의 코드에서는 첫 번째 열에 배치될 대상을 과감히 누락시켜야 밀리지 않습니다.

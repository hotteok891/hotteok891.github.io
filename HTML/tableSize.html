Table Size & Box Model

HTML 테이블은 일반적인 Block 블록 요소와 다르게 고유의 내부 컨텐츠 계산 체계를 가집니다. 전체 너비(Width), 높이(Height), 셀 패딩(Padding)이 연산되는 레이아웃 최적화 기법을 학습합니다.

테이블의 전체적인 형태를 잡는 가로·세로 폭 지정 방식과 패딩 속성의 상호작용입니다.

셀 패딩과 가독성 확보

테이블 내부의 가독성을 높이는 핵심 속성입니다. 테이블 자체에는 패딩이 먹지 않으며, 반드시 내부의 실제 데이터 셀인 <th>와 <td>에 스타일을 직접 정의해 주어야 콘텐츠 간격이 안정적으로 벌어집니다.

컨텐츠 유동성 고정 (table-layout: fixed)

기본 테이블은 셀 내부 텍스트가 길어지면 미리 지정한 너비 무시하고 늘어나는 성질을 가집니다. 이를 고정하여 균등 레이아웃을 생성하는 기법입니다.

⚠️ 깨지지 않는 테이블 레이아웃 설계 아키텍처 규칙

  • 1. 고정 너비 설계 시 필수 속성: 데이터 보드의 각 열 너비를 완벽히 통제하고 싶다면 반드시 부모 <table> 태그에 table-layout: fixed;와 width: 100%;(또는 특정 px 값)를 선언하고 최상단 첫 번째 행의 셀에 너비를 명시해야 합니다.
  • 2. 텍스트 넘침 제어 조합: fixed 모드를 주면 셀 내부 데이터가 넘쳤을 때 칸 밖으로 튀어나갈 수 있습니다. 이때 셀(td)에 overflow: hidden; text-overflow: ellipsis; white-space: nowrap; 속성을 조합해 말줄임표(...) 처리를 하는 것이 모던 대시보드 UI의 정석 패턴입니다.

HTML Heading Elements

h1부터 h6 태그는 웹 페이지의 문서 구조와 제목의 계층 체계를 정의합니다. 검색엔진 최적화(SEO)와 웹 접근성을 결정짓는 핵심 컴포넌트입니다.

H1 ~ H6 태그별 상세 분석

각 태그는 고유한 중요도 레벨을 가지며, 브라우저가 기본적으로 표현하는 폰트 크기가 다릅니다.

<h1>

최상위 제목

페이지당 단 하나만 사용하는 것을 권장하며, 웹페이지의 핵심 주제를 나타냅니다. 검색엔진이 가장 중요하게 취급합니다.

Browser Render
Heading 1
<h2>

주요 섹션 제목

웹페이지의 대단원이나 주요 섹션의 시작을 알립니다. 책의 '장(Chapter)'에 해당하는 역할을 수행합니다.

Browser Render
Heading 2
<h3>

서브 섹션 제목

h2의 하위 단락을 구성할 때 사용합니다. 구체적인 주제나 카테고리를 분류하기 좋습니다.

Browser Render
Heading 3
<h4>

세부 항목 제목

h3 내부에서 세부적인 요소나 리스트를 분류할 때 사용합니다. 일반적인 카드 UI의 제목 등으로 자주 쓰입니다.

Browser Render
Heading 4
<h5>

소분류 제목

복잡한 문서 구조에서 더 깊은 단계의 소제목이 필요할 때 사용됩니다. 사용 빈도는 다소 낮은 편입니다.

Browser Render
Heading 5
<h6>

최하위 분류 제목

HTML 제목 태그 중 가장 낮고 작은 단계를 나타냅니다. 매우 정밀하고 복잡한 구조의 기술 문서 등에서 찾아볼 수 있습니다.

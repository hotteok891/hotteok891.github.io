Hyperlink Element System

HTML 웹 생태계를 연결하는 핵심 요소인 <a> (Anchor) 태그의 작동 원리를 파악합니다. 단순 페이지 이동부터 내부 앵커 링킹, 그리고 모던 웹 표준 보안 규칙까지 완벽히 학습합니다.

HREF 주소 매핑 체계

href 속성에 선언하는 주소의 형태에 따라 브라우저가 리소스를 분기하는 방식입니다.

href="URL / Path"

절대 경로와 상대 경로 링크

외부 웹사이트로 연결할 때는 프로토콜(https://)을 포함한 전체 URL을 입력합니다. 프로젝트 내부 페이지를 연결할 때는 현재 파일 기준의 상대 경로(./about.html)를 사용합니다.

이동 경로 렌더링 예시
외부 위키백과 바로가기 →
href="#ID" & Tel/Mail

페이지 내부 앵커 및 고유 프로토콜

동일한 페이지 내의 특정 섹션으로 스크롤을 이동시키고 싶다면 해당 태그의 id 값을 고유 해시 기호(#)와 함께 연결합니다. 전화(tel:)나 이메일(mailto:) 프로토콜 링크도 지원합니다.

고유 기능 링크 렌더링 예시
↑ 최상단 비주얼 섹션으로 이동

윈도우 타겟 제어 및 웹 표준 보안

링크를 클릭했을 때 브라우저 탭을 새로 띄울지, 현재 화면을 전환할지 결정하는 컨텍스트 제어 메커니즘입니다.

Target Attribute Context Matrix

Target 속성값 기본 동작 상세 설명 및 아키텍처 규칙
_self 현재 탭 (기본값) 현재 문서를 로드하고 있는 기존 윈도우/탭 환경에서 링크 주소를 실행합니다. 속성을 생략하면 자동 적용됩니다.
_blank 새로운 탭 브라우저의 완전히 새로운 컨텍스트(새 탭 또는 새 창)를 생성하여 링크 페이지를 독립적으로 렌더링합니다.

⚠️ 새 탭(_blank) 링크 제어 시 필수 보안 아키텍처

  • 1. rel="noopener noreferrer" 의무화: 과거 브라우저 시스템 환경에서 target="_blank"를 단독 사용하면 링크된 새 페이지가 자바스크립트의 window.opener 객체를 악용하여 이전 부모 페이지를 하이재킹하거나 피싱 사이트로 조작하는 보안 취약점(Reverse Tabnabbing)이 존재했습니다.
  • 2. 최신 브라우저 보완 및 명시: 최신 모던 브라우저 엔진들은 `target="_blank"` 선언 시 암묵적으로 `noopener`를 자동 작동시키지만, 구형 브라우저 파편화 대응 및 완벽한 웹 어플리케이션 보안 무결성을 확보하기 위해 스타일 가이드라인 상 명시적으로 rel="noopener noreferrer" 속성을 패키징하여 작성하는 것이 프론트엔드 엔지니어링의 표준 규칙입니다.

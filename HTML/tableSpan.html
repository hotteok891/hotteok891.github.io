Table Span Attribute System

HTML 테이블의 데이터 셀(<td>, <th>)의 크기와 범위를 확장하는 핵심 메커니즘을 이해합니다. 가로축과 세로축 격자를 결합할 때 발생하는 레이아웃 연산 규칙을 완벽히 마스터할 수 있습니다.

두 가지 축의 병합 방식

열을 합치는 가로 병합과 행을 합치는 세로 병합의 선언 구조입니다.

HORIZONTAL AXIS
colspan="합칠 열의 개수"

Colspan : 가로 방향 열 병합

현재 셀을 기준으로 **오른쪽 방향**의 열(Column)들을 하나로 묶습니다. colspan="2"를 주면 자기 자신을 포함해 2칸을 차지하므로, 해당 행 내부에서 우측에 있던 원래의 <td> 코드 1개를 제거해야 공간이 유지됩니다.

실제 코드 연산 결과
colspan="2" (2칸 차지) 3번 칸
1번 칸 2번 칸 3번 칸
VERTICAL AXIS
rowspan="합칠 행의 개수"

Rowspan : 세로 방향 행 병합

현재 셀을 기준으로 **아래쪽 방향**의 행(Row)들을 하나로 묶습니다. rowspan="2"를 선언하면 다음 줄(<tr>)의 동일한 인덱스 위치에 위치할 셀 코드가 밀려나므로, **아래쪽 행 코드에서 해당 셀을 삭제**해야 격자가 유지됩니다.

실제 코드 연산 결과
rowspan="2"
(아래로 확장)		 A-2 칸
B-2 칸

복합 그리드 매트릭스 분석

셀 병합 시 테이블 구조가 깨지는 이유를 추적하기 위한 시각적 매핑 대시보드입니다. 빨간색 칸은 병합으로 인해 코드상에서 생략(삭제)되어야 하는 위치를 뜻합니다.

💡 테이블 무결성을 지키는 수치 연산 공식

  • 가로(colspan) 연산: 특정 행 안에 들어있는 모든 <td> 개수를 셀 때, colspan이 선언된 셀은 그 속성값만큼 숫자를 더해서 계산해야 합니다. (예: 1개 셀이 colspan="3"이면 총 3칸으로 인정)
  • 세로(rowspan) 연산: 위에서 아래로 밀고 들어오는 rowspan 계열 셀이 존재하면, 하위 행 트랙에서는 해당 칸의 인덱스 순서를 건너뛰고 다음 <td> 코드를 작성해야 구조 레이아웃이 우측으로 삐져나가는 현상을 방지할 수 있습니다.

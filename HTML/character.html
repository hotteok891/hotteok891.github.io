HTML 태그 백과사전

텍스트 강조 태그, 의미 있게 사용하는 방법

1. <strong> 태그

콘텐츠의 특정 부분이 매우 중요하거나, 심각하거나, 긴급함을 나타낼 때 사용합니다.

  • 시각적 효과: 브라우저가 기본적으로 글자를 굵게(Bold) 표시합니다.
  • 의미(Semantic): 웹 브라우저나 스크린 리더(시각장애인용 낭독기)에게 이 부분이 아주 중요한 정보임을 알립니다.
  • 사용 예시: 경고 문구, 핵심 키워드, 마감일 등

💻 코드 예시

<p>제출 기한은 <strong>오늘 자정까지</strong>입니다. 반드시 시간을 엄수해 주세요.</p>
👀 실제 화면 출력

제출 기한은 오늘 자정까지입니다. 반드시 시간을 엄수해 주세요.

2. <em> 태그 (Emphasis)

문장 안에서 특정 단어를 구어체처럼 강조(Emphasis)하여 말의 어조를 바꾸고 싶을 때 사용합니다.

  • 시각적 효과: 브라우저가 기본적으로 글자를 기울임꼴(Italic)로 표시합니다.
  • 의미(Semantic): 스크린 리더가 이 부분을 읽을 때 억양을 바꾸어 강조하여 낭독합니다. 어떤 단어를 강조하느냐에 따라 문장의 전체적인 뉘앙스가 달라집니다.

💻 코드 예시

<p>나는 그것을 <em>어제</em> 끝마쳤다. (다른 날이 아닌 어제 했다는 점을 강조)</p>
👀 실제 화면 출력

나는 그것을 어제 끝마쳤다. (다른 날이 아닌 어제 했다는 점을 강조)

💡 핵심 비교 및 주의사항

태그 기본 스타일 의미론적 핵심 (Semantic) 단순 스타일링 태그와 비교
<strong> 굵게 (Bold) 중요성, 심각성, 긴급함 의미 없이 단순히 굵게만 만들 때는 <b> 태그나 CSS 사용
<em> 기울임 (Italic) 말의 뉘앙스 강조, 스트레스 의미 없이 단순히 기울이기만 할 때는 <i> 태그나 CSS 사용
🔒 중요 포인트 (웹 표준):
과거에는 화면에 글자를 굵게 하거나 기울이기 위해 이 태그들을 썼지만, 현대 웹(웹 접근성 표준)에서는 "화면에 어떻게 보이는가"보다 "이 데이터가 어떤 의미를 담고 있는가"가 훨씬 중요합니다. 시각적인 효과만을 위해서라면 HTML 태그 대신 CSS(`font-weight`, `font-style`)를 사용하는 것이 좋습니다.

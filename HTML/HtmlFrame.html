HTML5 표준 문서 뼈대 구조

모든 웹 페이지의 기초이자 뼈대가 되는 W3C 표준 규격 코드의 계층 구조와 의미에 대한 정리입니다.

💻 HTML5 표준 기본 템플릿

웹 문서를 생성할 때 반드시 작성해야 하는 선언부와 최상위 구조입니다.

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>문서 제목</title>
</head>
<body>

    <!-- 브라우저 화면에 실질적으로 노출될 콘텐츠 작성 영역 -->
    <h1>Hello, World!</h1>

</body>
</html>

🔍 핵심 요소별 역할 분해

구조의 바깥쪽(선언부)부터 안쪽 계층 순으로 정의된 역할입니다.

<!DOCTYPE html>

**문서 형식 정의(DTD):** 현재 문서가 최신 표준 규격인 HTML5 문서임을 웹 브라우저에 선언합니다. 태그가 아닌 '선언문'입니다.

<html>

**최상위 루트(Root) 요소:** 모든 HTML 태그들의 부모가 되며, lang="ko" 속성을 부여해 문서의 주 언어가 한국어임을 브라우저와 검색엔진에 알립니다.

<head>

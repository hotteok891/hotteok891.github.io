<FRAME /> SPECIFICATION
<frame> HTML5 폐기 하나의 브라우저 창을 여러 구역으로 나누어 각각 독립된 HTML 문서를 보여주던 태그입니다.

💡 태그 개요

과거 웹 환경에서 브라우저 화면을 분할(예: 좌측 메뉴, 우측 본문)하기 위해 사용되던 레거시 태그입니다. 반드시 상위 컨테이너인 <frameset> 태그 내부에서만 선언될 수 있었으며, 일반적인 <body> 태그와는 함께 사용할 수 없다는 독특한 제약이 있었습니다.

⚠️ HTML5에서 완전히 제외된 이유

웹 접근성이 매우 떨어져 스크린 리더기가 페이지 구조를 읽기 어려웠고, 검색 엔진 최적화(SEO)에 치명적이었습니다. 또한 하나의 화면에 여러 주소의 문서가 섞여 있어 사용자가 특정 페이지를 북마크(즐겨찾기)하거나 뒤로 가기 버튼을 누를 때 오작동을 유발하여 표준에서 제외되었습니다.

💻 과거 사용 예시 코드 (구조 예시)

아래 코드는 화면을 좌우 20% 대 80% 비율로 분할하여 각각 다른 문서를 보여주던 옛날 방식의 레이아웃 구조입니다.

<!DOCTYPE html>
<html>

    <title>과거 프레임 레이아웃 예시</title>

<!-- body 태그 대신 frameset을 사용했습니다. -->
<frameset cols="20%, 80%">
    <frame src="menu.html" name="leftMenu">
    <frame src="main.html" name="mainContent">
    <noframes>
        <body>이 브라우저는 프레임을 지원하지 않습니다.</body>
    </noframes>
</frameset>
</html>

🚀 현대 웹에서의 대체안

오늘날 웹 표준 환경에서 프레임과 같은 레이아웃과 기능을 구현하려면 아래 기술을 사용해야 합니다.

  • ✨ CSS Flexbox / Grid: 단순 화면 레이아웃 분할은 프레임 태그가 아닌 순수 CSS 레이아웃 기술을 사용합니다.
  • ✨ <iframe> (Inline Frame): 본문(<body>) 내부의 특정 영역에만 제한적으로 외부 HTML 문서나 유튜브 영상 등을 삽입하고 싶을 때는 표준 태그인 아이프레임(iframe)을 사용합니다.

CSS 박스 모델 및 핵심 효과 가이드

경계선(Border), 여백(Margin/Padding), 그리고 박스 그림자(Box Shadow)의 완벽 이해

1. 경계선 스타일 (Border Styles)

CSS의 border-style 속성을 이용하면 요소를 둘러싸는 테두리의 외형을 다양하게 설정할 수 있습니다. 대표적인 8가지 기본 경계선 종류는 다음과 같습니다.

속성값 (Value) 설명
solid 가장 일반적인 단색 실선 테두리를 생성합니다.
dashed 일정 간격으로 끊어진 파선(대시선) 테두리를 생성합니다.
dotted 점선 모양의 테두리를 생성합니다. 부라우저에 따라 둥근 점으로 표현됩니다.
double 두 줄의 실선 테두리를 생성합니다. 선 두께의 합과 사이 공백이 지정한 두께가 됩니다.
groove 액자 틀처럼 안으로 홈이 파인 듯한 3D 입체 효과를 줍니다.
ridge groove와 반대로 테두리가 밖으로 볼록하게 튀어나온 듯한 3D 입체 효과를 줍니다.
inset 요소 전체가 화면 안쪽으로 창문처럼 푹 들어간 듯한 입체감을 줍니다.
outset inset과 반대로 요소 전체가 화면 앞으로 입체적으로 튀어나온 효과를 줍니다.

경계선 시각적 예제

solid (실선)
dashed (파선)
dotted (점선)
double (이중선)
groove (음각 홈)
ridge (양각 홈)
inset (음각 입체)
outset (양각 입체)

2. 마진(Margin)과 패딩(Padding)의 차이 및 종류

CSS 박스 모델(Box Model)의 핵심 요소인 마진과 패딩은 모두 여백을 다루지만, 적용되는 위치가 완전히 다릅니다.

  • 마진 (Margin): 테두리(Border)의 바깥쪽 여백입니다. 인접한 다른 요소와의 간격을 조절할 때 사용하며, 배경색을 가질 수 없습니다(투명).
  • 패딩 (Padding): 테두리(Border)의 안쪽 여백입니다. 콘텐츠와 테두리 사이의 간격을 조절하며, 요소에 지정된 배경색이나 배경 이미지가 그대로 채워집니다.

방향별 속성 분할

상하좌우 특정 방향만 개별적으로 제어하고 싶을 때는 아래의 세부 속성을 사용합니다.

방향 마진 속성 패딩 속성
상 (Top) margin-top padding-top
하 (Bottom) margin-bottom padding-bottom
좌 (Left) margin-left padding-left
우 (Right) margin-right padding-right

단축 속성(Shorthand) 적용 규칙

margin 또는 padding 하나의 속성에 공백을 두고 값을 나열하여 상하좌우를 한 번에 지정할 수 있습니다.

  • margin: 10px; → [값 1개] 상하좌우 모두 10px 적용
  • margin: 10px 20px; → [값 2개] 상하 10px, 좌우 20px 적용
  • margin: 10px 20px 30px; → [값 3개] 상 10px, 좌우 20px, 하 30px 적용
  • margin: 10px 20px 30px 40px; → [값 4개] 시계방향 순서대로 (상:10px, 우:20px, 하:30px, 좌:40px) 적용

박스 모델 공간 구성 시각화

마진 영역 (Margin Area - 바깥쪽 주황색 공간)
테두리 (Border - 파란색 선) 패딩 영역 (Padding Area - 안쪽 연두색 공간)
실제 콘텐츠 영역 (Content)

3. 박스 그림자 효과 (Box Shadow)

box-shadow 속성을 사용하면 2D 평면인 웹 페이지 요소에 그림자를 부여하여 깊이감(Depth)과 세련된 입체감을 표현할 수 있습니다.

box-shadow 문법 구성

box-shadow: X축이동거리 Y축이동거리 흐림정도(Blur) 확산크기(Spread) 색상;

  • X축 이동거리 (Horizontal Offset): 값이 양수면 오른쪽, 음수면 왼쪽에 그림자가 생깁니다. (필수)
  • Y축 이동거리 (Vertical Offset): 값이 양수면 아래쪽, 음수면 위쪽에 그림자가 생깁니다. (필수)
  • 흐림 정도 (Blur Radius): 그림자의 경계를 번지게 만듭니다. 값이 클수록 그림자가 흐릿하고 부드러워집니다.
  • 확산 크기 (Spread Radius): 그림자 자체의 크기를 사방으로 확장하거나 축소합니다.
  • 색상 (Color): 그림자의 색상을 지정합니다. 주로 반투명한 rgba() 형식을 사용하여 자연스럽게 묘사합니다.

그림자 스타일별 시각적 예제

기본 하드 그림자
5px 5px 0px 0px
부드러운 입체그림자
0px 10px 20px 0px
안쪽 그림자 (inset)
inset 0px 4px 8px

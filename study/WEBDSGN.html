궁금한 HTML 태그를 입력하거나 아래 라이브러리에서 선택하세요

<div> 레이아웃 / 블록

태그 설명이 여기에 표시됩니다.

사용 예제 (Usage Example)
<div class="container">
    <p>콘텐츠 영역입니다.<p>
</div>

주요 HTML5 태그 라이브러리

  • <div> 웹 페이지 요소를 그룹화하는 대표 블록 컨테이너
  • <a> 다른 페이지나 URL로 이동하는 하이퍼링크 생성
  • <img> 웹 문서에 이미지 파일(JPG, PNG, SVG) 삽입
  • <p> 하나의 독립된 텍스트 문단(Paragraph)을 구성
  • <table> 행과 열을 가진 격자 형태의 표 데이터 제작
  • <input> 사용자로부터 데이터를 입력받는 다양한 양식 제공
  • <video> 플러그인 없이 동영상(MP4 등) 스트리밍 및 재생
  • <span> 문장 내부 텍스트 일부를 묶어 스타일을 줄 때 사용하는 인라인 컨테이너

PYTHON PROGRAMMING GUIDE

📦 파이썬 모듈(Module) 완벽 정리

함수, 클래스, 변수를 하나의 .py 파일로 구조화하여 코드의 재사용성과 유지보수성을 극대화하는 파이썬 모듈 아키텍처를 학습합니다.

01

모듈의 개념과 사용하는 이유

모듈(Module)은 함수(Function), 클래스(Class), 변수 등을 하나의 파이썬 파일(.py)에 모아 놓은 단위입니다.

💡 핵심 원리: 자주 사용하는 기능(더하기, 평균 계산, 학생 관리, 원 넓이 계산 등)을 매번 새로 작성하지 않고 하나의 파일에 저장한 뒤, 필요한 곳에서 import 하여 가져다 사용합니다.

📐 모듈 구조 다이어그램

math.py ┌───────────────────────────────┐ │ add() │ │ sub() │ │ average() │ │ circle_area() │ └───────────────────────────────┘ └─► 필요한 함수만 가져와 재사용

🚀 모듈을 사용하는 4가지 이유

♻️ 코드 재사용
검증된 로직을 여러 프로젝트에서 반복 활용
🛠️ 유지보수 용이
기능 수정 시 해당 모듈 파일만 업데이트
🏗️ 체계적 구조화
기능별로 파일을 분리해 가독성 향상
🤝 원활한 협업
팀원 간 독립적인 모듈 개발 및 병합 가능

📚 모듈의 4가지 분류

종류 설명 및 예시
내장 모듈 파이썬에 기본 포함된 모듈 (math, random, os)
표준 라이브러리 표준으로 제공되는 모듈 (datetime, csv, json)
외부 모듈 pip로 설치하는 모듈 (numpy, pandas)
사용자 모듈 개발자가 직접 작성한 모듈 (mymath.py)

🔌 다양한 import 명령어 사용법

import_styles.py 
# 방법 1: 모듈 전체 불러오기
import math
print(math.sqrt(25))  # 5.0

# 방법 2: 특정 기능만 가져오기
from math import pi
print(pi)

# 방법 3: 모듈의 모든 기능 가져오기 (비권장: 이름 충돌 가능성)
from math import *
print(sqrt(16))

# 방법 4: 별칭(Alias) 붙이기 (가장 많이 활용됨)
import math as m
print(m.pi)

핵심 표준 모듈 실전 코드

🧮 math 모듈 (수학 연산)

math_example.py 
import math

print(math.pi)         # 원주율 (3.141592...)
print(math.sqrt(16))   # 제곱근 (4.0)
print(math.pow(2, 5))  # 거듭제곱 (32.0)
print(math.ceil(3.2))  # 올림 (4)
print(math.floor(3.8)) # 내림 (3)
print(math.factorial(5)) # 팩토리얼 (120)

🎲 random 모듈 (난수 생성)

random_example.py 
import random

# 1~10 사이의 임의의 정수
print(random.randint(1, 10))

# 리스트에서 임의로 하나 선택

# 리스트 요소 무작위 섞기
number = [1, 2, 3, 4, 5]
random.shuffle(number)
print(number)

⏱️ time 모듈 (시간 제어 및 성능 측정)

time_example.py 
import time

print("시작")
time.sleep(1)  # 1초 동안 대기
print("끝")

start_wall = time.perf_counter()
start_cpu = time.process_time()

total = sum(i * i for i in range(1_000_000))

print(f"실제 경과 시간: {time.perf_counter() - start_wall:.6f}초")
print(f"CPU 사용 시간: {time.process_time() - start_cpu:.6f}초")

데이터 포맷 처리 (CSV & JSON)

📊 csv 모듈 (CSV 파일 저장 및 읽기)

스프레드시트 및 데이터 분석에 널리 쓰이는 CSV 파일을 utf-8-sig 인코딩으로 안전하게 처리합니다.

csv_handler.py 
import csv

# CSV 쓰기
with open("output/score.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["이름", "Python", "AI"])
    writer.writerow(["홍길동", 95, 90])
    writer.writerow(["김철수", 88, 84])

# CSV 읽기
with open("output/score.csv", "r", encoding="utf-8-sig") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

🗂️ json 모듈 (JSON 직렬화 및 파싱)

파이썬 딕셔너리 객체를 JSON 파일로 저장(dump)하고 다시 객체로 불러옵니다(load).

json_handler.py 
import json

student = {
    "이름": "홍길동",
    "점수": 95
}

# JSON 파일 저장 (한글 깨짐 방지 및 들여쓰기)
with open("output/student.json", "w", encoding="utf-8") as f:
    json.dump(student, f, ensure_ascii=False, indent=4)

# JSON 파일 읽기
with open("output/student.json", "r", encoding="utf-8") as f:
    data = json.load(f)

print(data)

🎓 학생 성적 모듈 예제 (student.py)

student.py 
# student.py
def average(a, b, c):
    return (a + b + c) / 3

def grade(avg):
    if avg >= 90:
        return "A"
    elif avg >= 80:
        return "B"
    else:
        return "C"
main.py 
import student

avg = student.average(95, 90, 88)
print("평균:", avg)
print("학점:", student.grade(avg))

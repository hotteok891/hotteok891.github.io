1. 경계선 스타일 (Border Styles)

border-style 속성은 박스의 테두리 형태를 결정합니다. 다크 테마와 발광 효과가 어우러진 8가지 경계선 종류의 예제입니다.

속성값 설명 및 특징
solid가장 기본이 되는 깔끔한 단색 실선 테두리
dashed일정한 간격으로 잘려 있는 역동적인 파선 테두리
dotted촘촘한 점들로 이루어진 점선 테두리
double두 줄의 선이 겹쳐 보이는 이중선 테두리
groove안쪽으로 홈이 파인 듯한 네온 음각 입체 효과
ridge바깥으로 볼록하게 솟은 듯한 네온 양각 입체 효과
inset컨텐츠 전체가 안으로 파묻힌 듯한 입체 테두리
outset컨텐츠 전체가 바깥으로 튀어나온 듯한 버튼형 테두리

2. 마진(Margin)과 패딩(Padding)

박스 모델의 여백 레이어 시스템입니다. margin은 테두리 바깥의 타 요소와의 간격을 의미하며, padding은 테두리 안쪽과 실제 내용물 사이의 간격을 뜻합니다.

구분 마진 (Margin) 패딩 (Padding)
위치 테두리(Border)의 바깥쪽 영역 테두리(Border)의 안쪽 영역
배경색 투명성 유지 (배경색 지정 불가) 요소의 자체 배경색이 그대로 채워짐
세부 속성 margin-top / -right / -bottom / -left padding-top / -right / -bottom / -left
마진 영역 (Margin Area - 주황 파선 내부)
테두리 선 (Border Line - 파란 실선) 패딩 영역 (Padding Area - 초록 음영 내부)
실제 컨텐츠 (Content)

3. 네온 박스 그림자 (Box Shadow)

box-shadow 속성은 요소에 그림자 광채 효과를 부여합니다. 다크 모드에서는 색상값에 반투명한 네온 컬러나 밝은 원색을 지정해 화려한 레이저 발광 광채를 연출할 수 있습니다.

JavaScript DOM 요소 찾기

HTML 문서의 특정 태그, 아이디(ID), 클래스(Class)에 접근하여 텍스트와 스타일을 동적으로 제어하는 핵심 메서드를 분석합니다.

DOM이란? 개념

Document Object Model의 약자로, 브라우저가 HTML 문서를 이해하고 JavaScript로 조작할 수 있도록 트리(Tree) 구조로 변환한 객체 모델입니다.

동작 원리 프로세스

1. document 객체를 통해 원하는 요소를 탐색(Select)합니다.
2. 찾아낸 요소의 innerHTML이나 style 속성을 변경합니다.

기본 요소 탐색 메서드 분석

예제 10-1 코드에서 사용된 3가지 핵심 DOM 탐색 방식입니다.

getElementsByTagName 복수 반환

문서 내 동일한 태그 이름을 가진 모든 요소를 유사 배열(HTMLCollection) 형태로 가져옵니다. 따라서 [0]처럼 인덱스 번호를 지정해야 합니다.

// 첫 번째 <h1> 태그의 내용 변경
document.getElementsByTagName("h1")[0].innerHTML = 
  '첫번째 h1: getElementsByTagName';

getElementById 단일 반환

고유한 id 속성값을 가진 단 하나의 요소를 찾습니다. 페이지 내에서 유일하므로 인덱스 번호 없이 바로 속성을 제어할 수 있습니다.

// id="txt"인 요소의 내용 변경
document.getElementById('txt').innerHTML = 
  'getElementById';

getElementsByClassName 복수 반환

특정 class 이름이 부여된 모든 요소를 유사 배열로 반환합니다. 여러 요소에 공통 스타일을 적용할 때 주로 사용하며 인덱스가 필요합니다.

// 첫 번째 class="cls" 요소 변경
document.getElementsByClassName('cls')[0].innerHTML = 
  'getElementsByClassName';

확장 예시: 현대적인 CSS 선택자 방식

실무에서 가장 많이 쓰이는 querySelector와 스타일 제어 예시입니다.

querySelector() 추천

CSS 선택자 문법(#id, .class, tag)을 그대로 사용하여 조건에 맞는 가장 첫 번째 요소 하나를 반환합니다.

// 클래스가 cls인 첫 번째 요소의 글자색 변경
const target = document.querySelector('.cls');
target.style.color = '#38bdf8';

querySelectorAll() 전체 선택

조건에 일치하는 모든 요소를 NodeList로 반환하며, forEach() 반복문을 통해 한 번에 일괄 조작할 수 있습니다.

// 스테이지 내 모든 h1 요소에 밑줄 추가
document.querySelectorAll('.demo-stage h1')
  .forEach(el => el.style.textDecoration = 'underline');

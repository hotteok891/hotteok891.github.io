예제 10-2: DOM 요소 속성 변경
(Attribute Change)

웹 페이지 로드 이후 사용자 이벤트에 반응하여 HTML 태그의 속성(Attribute)과 인라인 스타일(Style)을 실시간으로 조작하는 핵심 원리를 분석합니다.

01. HTML 속성 변경 및 동적 제어 개념

💡 핵심 동작 원리 (Rendering & Repaint): JavaScript로 DOM 트리에 등록된 객체의 프로퍼티나 메서드를 호출해 값을 변경하면, 브라우저는 즉시 변경 사항을 감지하고 화면을 다시 렌더링(Repaint)하여 실시간 UI 변화를 구현합니다.

1) 프로퍼티 직접 접근

element.src와 같이 DOM 객체가 기본으로 내장한 프로퍼티에 직접 접근해 값을 대입합니다. 직관적이고 코드가 간결하여 표준 속성 변경 시 가장 많이 쓰입니다.

2) 인라인 스타일 객체 제어

element.style.color 형태로 CSS 스타일 속성을 개별 조작합니다. 하이픈(-)이 들어간 CSS 속성은 backgroundColor처럼 카멜케이스(CamelCase)로 작성합니다.

3) setAttribute() 메서드

setAttribute(name, value)를 호출해 속성명과 값을 문자열로 직접 전달합니다. 표준 속성뿐 아니라 사용자 정의 속성(data-*)을 부여하거나 기존 속성을 덮어쓸 때 유용합니다.

02. 제공된 HTML 원본 코드 및 실시간 테스트

아래는 분석 대상인 원본 HTML/JavaScript 코드입니다. 하단의 실행 버튼을 눌러 브라우저에서 직접 동작을 테스트할 수 있습니다.

example_10-2.html 
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
  <meta charset="utf-8">
  <title>예제10-2속성변경(attribute change)</title>
  <script>
    function changeImg(){
      document.getElementById("img").src = 'images/aisoftware.png';
    }
    function changeCss(){
      document.getElementById("cls").style.color = "red";
    }
    function changeSeta(){
      document.getElementById('set').setAttribute("style", "background-color:cyan");
    }
  </script>
</head>
<body id="main">
  <h1 style="text-align:center;">속성 변경(Find Element)</h1>
  <p>이미지 변경: <img id="img" src="images/ai.png" width="100px" height="100px"></p>
  <h2 id="cls" style="color:blue">CSS 속성(색상) 변경</h2>
  <h2 id="set" style="color:green">CSS setAttribute(attribute,value)</h2>
  <input type="button" id="bt1" value="change_img" onclick="changeImg();">
  <input type="button" id="bt2" value="change_style" onclick="changeCss();">
  <input type="button" class="bt3" value="change_setAttribute" onclick="changeSeta();">
</body>
</html>

03. 속성 제어 메서드 및 프로퍼티 상세 분석

예제에서 사용된 3가지 DOM 속성 조작 방식의 문법과 내부 동작 차이를 비교합니다.

구분 / 메서드 사용 예시 동작 설명 및 특징
src 프로퍼티 변경 document.getElementById("img").src = '...'; 이미지 태그(<img>)의 경로 프로퍼티를 직접 수정하여 웹 페이지에 로드되는 이미지 리소스를 동적으로 교체합니다.
style 객체 제어 document.getElementById("cls").style.color = "red"; 요소의 인라인 스타일(Inline Style) 객체에 접근하여 특정 CSS 속성값만 선택적으로 변경합니다. 기존에 적용된 다른 스타일은 유지됩니다.
setAttribute() document.getElementById('set').setAttribute("style", "..."); HTML 태그의 속성 이름과 값을 매개변수로 받아 강제로 설정합니다. style 속성에 사용할 경우 기존 인라인 스타일(color:green) 전체를 새 문자열로 덮어씌우는 특징이 있습니다.

04. 학습 핵심 정리

리소스 동적 전환

element.src = '경로'를 활용하면 페이지 새로고침 없이 이미지나 미디어 소스를 즉시 바꿀 수 있습니다.

개별 스타일 조작

element.style.속성명 = '값'은 다른 스타일을 보존하면서 특정 디자인 속성만 핀포인트로 수정할 때 적합합니다.

범용 속성 덮어쓰기

element.setAttribute(속성, 값)은 태그의 속성 자체를 재정의하므로 기존 속성값을 완전히 교체할 때 사용합니다.
